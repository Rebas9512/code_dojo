# code-dojo 教学设计

> 2026-11-22。按用户决定"按 0 基础的人来做"和"题课合一"（`docs/problem-format.md` v1.4）写：每个技能有一段教学内容（讲解 → 带步骤名的示例 → 小测），挂在用到它的题旁边；题目阶梯（预测 → 补全 → 改错 → 独立写 → 变式 → 组合）就是这个技能的练习。
> 依据：`docs/reports/编程教学 交互与流程 调研.md` 第"三条线各有一个核心心智模型"和"各板块的教学设计模板"两节（不采用其中的诊断先行和跳过逻辑）。学习顺序和题单见 `docs/curriculum.md`。
> 认识数据有 20 题和 2 个课文件，Python 0A 第 0–10 组有 207 题和 11 个课文件，SQL 阶段 0 有 44 题和 4 个课文件。下表列出已写部分的题目与课，以及后续模块的教学设计。

## 1. 通用做法

### 1.1 一个技能的教学内容（课）

每个技能写在某个 `lessons/<id>/lesson.yaml` 里，三种步骤都标明 `skill`：

1. **讲解（read，150–500 字）**：固定三段——**是什么、为什么**（这个东西解决什么问题）→ **怎么写**（最小语法 + 一个小例子）→ **常见误解**（每条用"加粗的错误说法 + 为什么错"写出来，对应第 2、7 节目录里的编号）。默认读者从没学过，不用"你应该还记得"。
2. **示例（example）**：数据课用数据块展示登记、文件原文或表结构；代码课用一段能运行的完整代码。用 `# ①`、`# ②`、`# ③` 注释给每个功能步骤起名字（子目标），同一个名字以后出现在补全题挖空的位置、作者提示和 AI 提示里。示例下面一句"把……改成……再运行"，让学习者动手改一处、看结果怎么变（通常正好暴露一条误解）。
3. **小测（quiz，0–2 道单选）**：每道针对一条具名误解；错误选项就是持有这条误解的人会选的答案，`explain` 说明为什么。

写法约束（检查脚本核对）：示例只能用这个技能、它的前置、以及学习顺序里更早引入的技能；每个技能只在一个文件里讲；文字里不写"上一节 / 下一组"之类的位置引用，方便以后调整顺序。

### 1.2 题目阶梯怎样练这个技能

| 级 | 题型 | 做法 | 针对什么 |
|---|---|---|---|
| 1 | 预测 | 程序就是示例的一个变形，故意把最常见的误解放进去（比如在 for 里改 i、`x == 1 or 2`） | 具名误解；先读懂再写 |
| 2 | 补全 | **逆向渐隐**：先只挖掉最后一个子目标（或新语法的那一小块），之后的题多挖一步 | 第一次动手写新语法 |
| 3 | 改错（可选） | 起始代码是一个典型错误写法，题面描述错误现象；bug 在 examples 上就能看到 | 常见坑：差一错误、条件顺序、初始值、NULL |
| 4 | 独立写 | 只给签名；任务和示例同构，但换了数据和外壳 | 计入掌握 |
| 5 | 变式 / 组合 | 换条件、换外壳，或和 1–2 个旧技能组合 | 迁移 |

SQL 没有预测题型（见 curriculum 第 9 节），第 1 级用课里的小测代替（"这条查询返回几行""这一行得到哪个标签"），第 2 级起和 Python 一样。

### 1.3 三条线的核心心智模型

- **Python 基础：名字是贴在值上的标签，程序是一步步改变"贴纸状态"的机器。** `=` 先算右边再贴名字；函数调用时参数是新贴的名字，return 把一个值送回调用处；列表是可以改的对象，名字只是指向它。讲解和预测题都围绕"执行到这一行时，每个名字贴在什么值上"，追踪表（每轮一行）是主要工具。
- **算法与数据结构：信号 + 不变式 + 带步骤名的模板 + 一个不适用的反例。** 每个套路课先说"题目里出现什么信号就该想到它"，再给一句不变式（如"窗口 [l, r] 始终满足约束"），然后是 3–6 个子目标组成的模板，一个逐步追踪的示例，最后一个**这个套路不适用**的反例（如有负数时滑动窗口失效）。
- **递归和 DP：先建立"副本模型"，再用 SRTBOT。** 每次调用是一个有自己变量的新副本；先让学习者自己填 2–3 层的调用树和每个节点的返回值，会追踪之后才讲"相信递归调用"。DP 按 子问题 → 递推 → 拓扑序 → 基例 → 原问题 → 时间（SRTBOT）写成文字，先记忆化再填表。
- **SQL：查询是按逻辑顺序逐步变换的表。** FROM → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT；示例尽量展示每个子句之后的中间表；练习重点放在"能运行但答错"（NULL、并列、重复、边界、扇出），这正是隐藏数据集和 `wrong_examples` 要抓的东西。

### 1.4 套路课模板（阶段 1–4）

每个套路技能的教学内容固定为：

| 部分 | 写什么 |
|---|---|
| 讲解 | 信号（看到什么样的题该想到它）→ 不变式（一句话）→ 模板的子目标列表 → 复杂度 → 常见误解 → 反例（什么时候不能用） |
| 示例 | 模板的完整实现，子目标写成 `# ①` 注释；再配一个小输入的追踪表（每一步变量 / 指针 / 栈 / 队列的状态） |
| 小测 | 1 道"这一步之后状态是什么"，1 道"这道题能不能用这个套路"（反例） |
| 阶梯 | 桥题（自写，最小规模，只练这个套路）→ 最简单的骨架题 → 同类骨架题 → 后面的组合题；补全题按子目标从后往前挖空 |

### 3.2 条件和布尔逻辑（`py-0a-l02-conditions`）

- **核心心智模型**：比较得到 True / False；if / elif / else 从上往下找第一个成立的分支，只走一条；return 让函数立刻结束；and / or 会短路。
- **主示例**：门票（if / else，结果存进同一个变量再 return）→ describe（守卫式提前 return）→ 分数转等级（elif，从高往低只写下限）。
- **特别注意**：同一个 95 分分别用 if / if / if 和 if / elif / elif 写，对比输出（PM12）；`x == 1 or 2`（PM14）。

### 3.3 循环（`py-0a-l03-loops`）

- **核心心智模型**：for 把名字依次贴到 range 的每个数上；range 左闭右开，长度是 b − a；while 只在每轮顶部检查条件；累加器"循环前初始化、循环里更新、循环后读取"；打擂台"第一个值当擂主、逐个挑战、更好就换"。
- **主示例**：1 到 n 求和（追踪表：每轮一行 i 和 total）；数字有几位（while）；最大的那一位（打擂台）。

## 张量与 PyTorch 的具名误解

形状预测先数轴，再沿一个具体格子追踪值。反向传播和模块题分别记录前向值、梯度和参数身份。每项误解都在对应的课中配有可修改的小实验与小测。

| 编号 | 常见误解 | 用来辨别的实验 | 练习 |
|---|---|---|---|
| TM01 | 把一行表看成一串数 | 在 [8, 9] 外再套一对方括号，形状从 (2,) 变为 (1, 2)，读数仍是两个。 | `tensor-1-001-three-layouts` |
| TM02 | 把指定宽度当成行数 | 六张标签每行放两张，reshape(-1, 2) 得到三行两列。每行两张沿着原顺序读。 | `tensor-1-004-repack-shapes` |
| TM03 | 以为换轴后的相邻格在内存里也相邻 | 把 0 到 5 排成两行三列再转置，第一行要读 0、3。此时 view(-1) 会报错；reshape(-1) 或 contiguous().view(-1) 得到 [0, 3, 1, 4, 2, 5]。 | `tensor-1-009-fix-transposed-view` |
| TM04 | 把所有长度为一的轴都挤掉 | 形状 (1, 3, 1) 只 squeeze(2) 会留下 (1, 3)；无参数 squeeze() 还会挤掉开头的一批。 | `tensor-1-013-remove-channel` |
| TM05 | 用一维行补偿去对齐最后的列 | 两行两列加 [10, 20] 会给第二列加 20。若要给第二行加 20，先把补偿写成 [[10], [20]]。 | `tensor-1-015-row-shift` |
| TM06 | 漏掉 keepdim 导致行均值对齐列 | 两行均值是 2 和 7 时，一维的 [2, 7] 会对齐末轴。保留列轴得到 [[2], [7]]，每格才能减去本行均值。 | `tensor-1-019-fix-row-center` |
| TM07 | 混淆取一格与切出一格宽的区间 | 三行两列的 x 取 x[:, 0] 得 (3,)，而 x[:, 0:1] 得 (3, 1)。 | `tensor-2-001-slice-trail` |
| TM08 | 把填补坏读数做成筛掉坏读数 | 读数 [[3, -1, 3]] 只有一个负值。掩码取数得到 [-1]，把负数填零得到 [[3, 0, 3]]。 | `tensor-2-004-mask-or-fill` |
| TM09 | 让每一行都使用第一行的地址 | 两行 [4, 7, 2]、[9, 6, 1] 按 [[1], [0]] 查，分别取回 7、9，第二行用自己的列号。 | `tensor-2-007-address-shapes` |
| TM10 | 用本批出现的类别数决定输出宽度 | 目录有五类时，两个标签 [1, 1] 也要编码成两行五列；四个未出现的类别各留一列。 | `tensor-2-010-category-width` |
| TM11 | 把真假分支的候选顺序颠倒 | 主读数 [0, -2]、备用 [6, 7]，以主读数非负为有效，真假分支依次给出 0、7。 | `tensor-2-013-which-wire` |
| TM12 | 把最大值当作它的位置 | 读数 [7, 7, 2] 的最大值是 7，argmax 给位置 0，相同最大值选择先遇到的那格。 | `tensor-2-017-first-winner` |
| TM13 | 把目的地编号直接当成来源编号 | 四格右移一格时，输出第零格要读原第三格。减一步得到来源地址，超过边界用余数绕回。 | `tensor-2-028-roll` |
| TM14 | 把重复字母的各项乘积当成最终结果 | 数量 [2, 3] 与单价 [4, 5] 的两项贡献为 8 和 15。材料轴从输出消失时，还要加成 23。 | `tensor-3-001-contract-shape` |

| TM21 | 把能求导的普通张量当成已经登记的参数 | 把普通浮点张量和 Parameter 分别挂到模块属性上，即使两者都能求导，也只有 Parameter 会自动出现在参数清单中。 | `tensor-4-014-wrap-gains` |
| TM22 | 按输入数、输出数的顺序存权重 | 三个输入、两个输出时，每个输出需要三个系数。weight 是 (2, 3)，四个样本的输出则是 (4, 2)。 | `tensor-4-016-weight-or-output` |
