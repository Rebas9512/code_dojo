语料中的每个字符需要一个稳定编号，训练时把原文编码，生成后再解码。前面练过 BPE；这里沿用字符级词表来缩小输出层、省去合并训练，让整个项目能在 CPU 上快速跑完。

## 接口

`CharVocab(text)` 保存 `chars`（按 Unicode 码点升序的不同字符序列）。`encode(text)` 返回 Python 整数列表，`decode(ids)` 返回字符串。编号从 0 起，重复出现的字符共用编号。

## 示例

用 `v = CharVocab("cab")` 建表后，`v.encode("cab")` 得到 `[2, 0, 1]`，`v.decode([0, 2])` 得到 `"ac"`。用 `CharVocab("aba\n")` 编码 `"a\n"` 得到 `[1, 0]`。

## 约束

建表文本非空。消息可为空，字符和编号一定在词表里。空格、换行、大小写都保留。
