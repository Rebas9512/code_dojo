# 训练文本

`pride.txt` 收录 Jane Austen《Pride and Prejudice》（《傲慢与偏见》，1813 年）的英文第 1–18 章。这部作品在美国属于公有领域，可复制、修改和再分发。[Project Gutenberg 第 1342 号书目与版权状态](https://www.gutenberg.org/ebooks/1342)

正文来自第 1342 号电子书的 ASCII 纯文本版本。从独占一行的 `Chapter 1` 截至 `Chapter 19` 标题之前，保留标点、大小写和段落，将换行统一成 LF，文末保留一个换行。训练文件只含作品正文和章标题，共 180,837 字节、74 种字符。[下载所用的纯文本](https://raw.githubusercontent.com/GITenberg/Pride-and-Prejudice_1342/master/1342.txt)
