## 题目

books 有 id、name，lots 有 id、n。按 id 配对，返回每个匹配组合的 id、name、n 三列。补全起始代码中的 `____`。

`books`、`lots` 已经是 DataFrame。

## 示例 1

`books`

| id | name |
| --- | --- |
| 1 | 甲 |
| 2 | 乙 |

`lots`

| id | n |
| --- | --- |
| 1 | 2 |
| 1 | 3 |
| 3 | 4 |

返回

| id | name | n |
| --- | --- | --- |
| 1 | 甲 | 2 |
| 1 | 甲 | 3 |

## 示例 2

`books`

| id | name |
| --- | --- |
| 2 | 乙 |

`lots`

| id | n |
| --- | --- |
| 4 | 8 |

返回

| id | name | n |
| --- | --- | --- |

（空表）

按示例的列名和列顺序返回。行的排列顺序可自选。行索引可自选。
