## 题目

借出表 loans 和归还表 returns 用 id 标识一次借阅，两表内的 id 各自唯一。只报告已经配对的记录，返回 id、days 两列。days 为 end 减 start 的天数，同日为 0，提前时可为负。

`loans`、`returns` 已经是 DataFrame。

## 示例 1

`loans`

| id | start |
| --- | --- |
| 3 | 2024-02-28 |
| 7 | 2024-03-01 |
| 8 | 2024-02-28 |

`returns`

| id | end |
| --- | --- |
| 7 | 2024-02-28 |
| 3 | 2024-03-01 |

返回

| id | days |
| --- | --- |
| 3 | 2 |
| 7 | -2 |

## 示例 2

`loans`

| id | start |
| --- | --- |
| 3 | 2025-12-31 |
| 7 | 2026-01-01 |
| 8 | 2025-12-31 |

`returns`

| id | end |
| --- | --- |
| 7 | 2025-12-31 |
| 3 | 2026-01-01 |

返回

| id | days |
| --- | --- |
| 3 | 1 |
| 7 | -1 |

按示例的列名和列顺序返回。行的排列顺序可自选。行索引可自选。
