## 题目

day 列存有效的 YYYY-MM-DD 日期文字。返回同名 Series，每个值是 1 到 12 的月号。补全起始代码中的 `____`。

`t` 已经是 DataFrame。

## 示例 1

`t`

| day |
| --- |
| 2024-02-28 |
| 2024-03-01 |

返回

| day |
| --- |
| 2 |
| 3 |

`t`

| day |

| day |
| --- |

| 1 |
