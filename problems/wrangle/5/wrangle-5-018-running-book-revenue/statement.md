## 题目

daily_sales 是书店从非取消订单明细按天汇总的表。day 是 YYYY-MM-DD，每个营业日只有一行。按日期升序返回 day、amount、total，total 为截至当天的累计金额。

`daily_sales` 已经是 DataFrame。

## 示例 1

`daily_sales`

| day | amount |
| --- | --- |
| 2025-06-25 | 31.0 |
| 2025-06-20 | 70.0 |
| 2025-06-18 | 45.0 |

返回

| day | amount | total |
| --- | --- | --- |
| 2025-06-18 | 45.0 | 45.0 |
| 2025-06-20 | 70.0 | 115.0 |
| 2025-06-25 | 31.0 | 146.0 |

## 示例 2

`daily_sales`

| day | amount |
| --- | --- |
| 2025-06-01 | 48.0 |
| 2025-05-31 | 59.0 |
| 2025-05-20 | 42.0 |

返回

| day | amount | total |
| --- | --- | --- |
| 2025-05-20 | 42.0 | 42.0 |
| 2025-05-31 | 59.0 | 101.0 |
| 2025-06-01 | 48.0 | 149.0 |

按示例的列名和列顺序返回。行的排列顺序也要一致。行索引可自选。

同一道书店查询的 SQL 练习为 [sql-4-012-running-book-revenue](/p/sql-4-012-running-book-revenue)。
