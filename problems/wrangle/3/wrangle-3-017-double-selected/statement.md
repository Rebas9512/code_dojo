## 题目

t 的 shelf 是货架名，n 是现有册数。指定货架的每一行册数翻倍，其他货架保持原值，按更新后的 n 从小到大排列，同册数按 shelf 升序。

`t` 已经是 DataFrame。

## 示例 1

`t`

| shelf | n |
| --- | --- |
| 甲 | 2 |
| 乙 | 4 |

`shelf`

`'甲'`

返回

| shelf | n |
| --- | --- |
| 乙 | 4 |
| 甲 | 4 |

## 示例 2

`t`

| shelf | n |
| --- | --- |
| 丙 | 0 |

`shelf`

`'甲'`

返回

| shelf | n |
| --- | --- |
| 丙 | 0 |

按示例的列名和列顺序返回。行的排列顺序也要一致。行索引可自选。
