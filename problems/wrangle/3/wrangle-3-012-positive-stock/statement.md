## 题目

t 有 id、stock 两列；按输入顺序返回 stock 大于零的行，仅保留 id 一列。补全起始代码中的 `____`。

`t` 已经是 DataFrame。

## 示例 1

`t`

| id | stock |
| --- | --- |
| 3 | 4 |
| 1 | 0 |
| 2 | 4 |

返回

| id |
| --- |
| 3 |
| 2 |

## 示例 2

`t`

| id | stock |
| --- | --- |
| 1 | 0 |

返回

| id |
| --- |

（空表）

按示例的列名和列顺序返回。行的排列顺序也要一致。行索引可自选。
