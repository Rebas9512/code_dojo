## 题目

快递运费规则（重量 `weight` 是整数千克）：

| 重量 | 运费 |
|---|---|
| 不超过 1 千克 | 10 元 |
| 超过 1、不超过 5 千克 | 15 元 |
| 超过 5、不超过 20 千克 | 30 元 |
| 超过 20 千克 | 50 元 |

编辑器里的代码算 3 千克的运费得到 30 元，不对。找出问题并修好它。

## 示例

**示例 1**

```
输入：weight = 3
输出：15
```

**示例 2**

```
输入：weight = 25
输出：50
```

## 约束

- `1 <= weight <= 1000`
