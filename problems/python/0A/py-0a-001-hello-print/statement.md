## 题目

读题目给出的程序，写出它运行后打印的**全部内容**。

这题想让你注意：
- 带引号的是文字，原样输出；不带引号的数字直接输出。
- `print(a, b)` 会在两个值之间放**一个空格**。
- `print()` 什么都不传时，输出一个空行（空行也要写出来）。

- 观察最后两次调用 `print(7)` 和 `print("7")`：输出能看出原来的类型吗？

## 示例

如果程序是

```python
print("a")
print(1, 2)
```

答案就写成两行：

```
a
1 2
```

## 约束

- 只写程序的输出，不要写代码。
- 按打印顺序，一个 `print` 一行。
- 行尾空格和末尾多余的空行不影响判定。
