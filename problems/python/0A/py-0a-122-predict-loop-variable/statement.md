## 题目

读题目给出的程序，写出它运行后打印的**全部内容**。

这题想让你注意：
- for 每一轮都会把 i **重新**设成 range 里的下一个数；在循环体里改 i 不影响下一轮。
- `range(1, 1)` 里一个数都没有，循环体一次也不执行。
- `range(1, 4)` 不包含 4。

## 示例

如果程序是

```python
print("a")
print(1, 2)
```

答案就写成两行：

```
a
1 2
```

## 约束

- 只写程序的输出，英文字母按程序显示的大小写填写。
- 按打印顺序，一个 `print` 一行。
- 行尾空格和末尾多余的空行不影响判定。
