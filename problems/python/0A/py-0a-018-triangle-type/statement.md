## 题目

给三条边长 `a`、`b`、`c`，判断它们能组成什么三角形，返回对应的小写英文标签：

- `"invalid"`：存在两边之和**不大于**第三边；
- `"equilateral"`：三边都相等；
- `"isosceles"`：恰好有两边相等；
- `"scalene"`：其他情况。

## 示例

**示例 1**

```
输入：a = 3, b = 3, c = 3
输出："equilateral"
```

**示例 2**

```
输入：a = 3, b = 4, c = 5
输出："scalene"
```

## 约束

- `1 <= a, b, c <= 10^6`
