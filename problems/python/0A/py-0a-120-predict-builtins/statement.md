## 题目

读题目给出的程序，写出它运行后打印的**全部内容**。

这题想让你注意：
- `min` / `max` 可以一次比较多个数。
- `round(x, 2)` 保留两位小数。
- `round(2.5)` 是 2、`round(3.5)` 是 4：正好 .5 时取**偶数**，不是一律进一。

## 示例

如果程序是

```python
print("a")
print(1, 2)
```

答案就写成两行：

```
a
1 2
```

## 约束

- 只写程序的输出，不要写代码。
- 按打印顺序，一个 `print` 一行。
- 行尾空格和末尾多余的空行不影响判定。
