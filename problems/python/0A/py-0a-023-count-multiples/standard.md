## 思路

逐个检查从 1 到 n 的整数，余数为 0 就说明可以整除。能被 3 或 5 中任意一个整除，都把这个数计入一次。

## 复杂度

每个整数最多取两次余数，时间 O(n)，额外空间 O(1)。

## 写法要点

- 把两个条件用 `or` 连在同一个判断里，15 这样的公倍数只会加一次。

## 进阶写法

如果只需要总个数，可以直接数完整的 3 个一组和 5 个一组。15 的倍数两边都算过，减去一次后只需固定次数的整除。

```python
def count_multiples(n: int) -> int:
    return n // 3 + n // 5 - n // 15
```
