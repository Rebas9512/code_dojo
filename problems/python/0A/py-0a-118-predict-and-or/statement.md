## 题目

读题目给出的程序，写出它运行后打印的**全部内容**。

这题想让你注意：
- `x == 1 or 2` **不是** "x 等于 1 或 2"：or 左边为假时，结果就是右边的值 2。
- and 左边已经是 False 时，右边**根本不会计算**（短路）——所以最后一行的 `1 / 0` 不会报错。

## 示例

如果程序是

```python
print("a")
print(1, 2)
```

答案就写成两行：

```
a
1 2
```

## 约束

- 只写程序的输出，不要写代码。
- 按打印顺序，一个 `print` 一行。
- 行尾空格和末尾多余的空行不影响判定。
