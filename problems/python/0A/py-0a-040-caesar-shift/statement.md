## 题目

把字符串 `s` 中每个**小写字母**往后移 `k` 位（`z` 之后回到 `a`），其他字符保持不变，返回结果。
例如 `k = 3` 时 `"xyz"` → `"abc"`。

思路：把字母换成 0–25 的编号 `ord(ch) - ord("a")`，加上 `k` 后对 26 取余，再加回 `ord("a")`，用 `chr` 转回字符。

## 示例

**示例 1**

```
输入：s = "abc", k = 1
输出："bcd"
```

**示例 2**

```
输入：s = "xyz", k = 3
输出："abc"
```

## 约束

- `0 <= len(s) <= 10^4`
- `0 <= k <= 1000`
