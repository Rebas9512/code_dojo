## 题目

在列表 `nums` 中找两个**不同位置**的数，使它们的和等于 `target`，返回这两个位置 `[i, j]`（`i < j`）。
如果有多组，返回 `i` 最小的那组；`i` 相同时返回 `j` 最小的。找不到返回空列表 `[]`。

这是"两数之和"的暴力解法：两层循环枚举所有 `i < j` 的组合。阶段 1 会学只扫一遍的哈希表写法。

## 示例

**示例 1**

```
输入：nums = [2, 7, 11, 15], target = 9
输出：[0, 1]
```

**示例 2**

```
输入：nums = [3, 2, 4], target = 6
输出：[1, 2]
```

## 约束

- `0 <= len(nums) <= 1000`
- `-10^9 <= nums[i], target <= 10^9`
