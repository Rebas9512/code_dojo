## 题目

读题目给出的程序，写出它运行后打印的**全部内容**。

这题想让你注意：
- `def` 只是**定义**函数，这时函数体还没有运行；调用 `double(5)` 时才运行。
- `return` 把值交回给调用的地方：`a = double(5)` 把结果存进 a。
- 只调用、不打印（`double(7)` 单独一行），结果就被丢掉了，屏幕上什么都不会出现。

## 示例

如果程序是

```python
print("a")
print(1, 2)
```

答案就写成两行：

```
a
1 2
```

## 约束

- 只写程序的输出，不要写代码。
- 按打印顺序，一个 `print` 一行。
- 行尾空格和末尾多余的空行不影响判定。
