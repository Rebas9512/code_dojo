## 题目

读题目给出的程序，写出它运行后打印的**全部内容**。

这题想让你注意：
- `split()` 不带参数：按任意多个空白切，不会出现空串。
- `split(" ")` 带参数：严格按一个空格切，连续两个空格之间会切出一个空串 `''`。
- `join` 是**分隔符**的方法：`"-".join(["x", "y"])`。

## 示例

如果程序是

```python
print("a")
print(1, 2)
```

答案就写成两行：

```
a
1 2
```

## 约束

- 只写程序的输出，不要写代码。
- 按打印顺序，一个 `print` 一行。
- 行尾空格和末尾多余的空行不影响判定。
