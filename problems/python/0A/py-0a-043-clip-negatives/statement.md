## 题目

把列表 `nums` 中的负数都改成 0，**直接修改原列表**（不要新建列表），最后返回这个列表。

注意：`for x in nums` 拿到的是元素的值，给 `x` 赋值不会改动列表；要改列表里的元素，需要用下标 `nums[i] = 0`。

## 示例

**示例 1**

```
输入：nums = [1, -2, 3]
输出：[1, 0, 3]
```

**示例 2**

```
输入：nums = [-5, -1]
输出：[0, 0]
```

## 约束

- `0 <= len(nums) <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
