## 题目

读题目给出的程序，写出它运行后打印的**全部内容**。

这题想让你注意：
- `grid[i]` 是第 i 行（一个列表），`grid[i][j]` 是第 i 行第 j 列的元素。
- `len(grid)` 是行数，`len(grid[0])` 是列数。
- `for row in grid` 每次拿到一整行。

## 示例

如果程序是

```python
print("a")
print(1, 2)
```

答案就写成两行：

```
a
1 2
```

## 约束

- 只写程序的输出，不要写代码。
- 按打印顺序，一个 `print` 一行。
- 行尾空格和末尾多余的空行不影响判定。
