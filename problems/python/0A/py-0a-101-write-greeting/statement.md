## 题目

写一个程序，按以下大小写输出三行，第一行使用全角逗号：

```
hello，Python
I practice at code-dojo
2026
```

第三行的 2026 请写成数字（不加引号）。

**示例 1**

输入：

（没有输入）

输出：

```
hello，Python
I practice at code-dojo
2026
```

（没有输入）

输出：

```

```

## 约束

- 没有输入。
- 每行末尾的空格和最后多出的空行不影响判定。
