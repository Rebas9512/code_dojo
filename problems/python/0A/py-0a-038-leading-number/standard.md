## 思路

从左向右读，把开头遇到的数字依次接起来。第一个非数字就是这一段的终点，后面再出现的数字与答案无关。

## 复杂度

设开头有 k 个数字，最多检查 k+1 个字符。逐次拼接若复制已有前缀，最坏时间 O(k²+1)，包括构造字符串的额外空间 O(k+1)。

## 写法要点

- 遇到非数字就 `break`，像 `"42abc7"` 只会留下 `"42"`。保留字符还能保住开头的零。

## 进阶写法

想少做字符串拼接时，可以只数开头有几个数字，遇到第一个非数字就停下。最后一次切片取出这段前缀，k 个开头数字只需 O(k+1) 时间。

```python
def leading_number(s: str) -> str:
    end = 0
    for ch in s:
        if not ch.isdigit():
            break
        end += 1
    return s[:end]
```
