## 题目

三根柱名分别是 start（起点）、spare（临时）、end（终点）。把 n 个由小到大叠放的圆盘从起点搬到终点，一次移动顶上的一盘，大盘不能压在小盘上。按这三步生成记录：先借终点把上面 n−1 盘移到临时柱，再移底盘到终点，最后借起点把临时柱的 n−1 盘移到终点。每步写成“起柱→落柱”，返回整张列表。

## 示例

**示例 1**

```text
输入：n = 2, start = 'A', spare = 'B', end = 'C'
输出：['A→B', 'A→C', 'B→C']
```

**示例 2**

```text
输入：n = 1, start = '东', spare = '中', end = '西'
输出：['东→西']
```

## 约束

0 ≤ n ≤ 8，三个柱名互不相同，均为非空字符串；0 盘返回空列表。
