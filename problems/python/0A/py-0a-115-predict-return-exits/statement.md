## 题目

读题目给出的程序，写出它运行后打印的**全部内容**。

这题想让你注意：
- 函数执行到 `return` 就**立刻结束**，后面的代码不再运行。
- 所以 n = 20 时，第一个 if 就 return 了，不会再去看第二个 if。
- 两个 if 都不成立时，才会走到最后一行的 return。

## 示例

如果程序是

```python
print("a")
print(1, 2)
```

答案就写成两行：

```
a
1 2
```

## 约束

- 只写程序的输出，不要写代码。
- 按打印顺序，一个 `print` 一行。
- 行尾空格和末尾多余的空行不影响判定。
