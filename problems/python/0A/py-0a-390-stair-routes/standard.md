## 思路

按最后一步分组，迈 1 级的走法来自 n−1 级，迈 2 级的走法来自 n−2 级。两组互不重叠，直接相加。0 级和 1 级各有一种走法。

## 复杂度

设楼梯有 n 级，每次调用最多分成两支，例如算 5 级和算 4 级时都会再算 3 级。这样重复展开，时间上界为 O(2ⁿ)，最长调用链占 O(n) 额外空间。

## 写法要点

- 把 0 级记成一种“什么都不走”的走法，n 为 2 时才会同时数到一步迈两级和分两次各迈一级。

## 进阶写法

如果层数再大些，可以用 `cache` 记住每个层数已经算出的答案。这样仍沿用同一递归关系，只需计算 O(n) 个不同的层数，缓存和调用合计占 O(n) 空间。

```python
from functools import cache


@cache
def routes(n: int) -> int:
    if n <= 1:
        return 1
    return routes(n - 1) + routes(n - 2)
```
