## 题目

读题目给出的程序，写出它运行后打印的**全部内容**。

这题想让你注意：
- `b = a` 是让 b 也贴到 a **现在**的值上；之后 a 再变，b 不会跟着变。
- `c = a * 2` 算出来就存好了，之后改 a 不会影响 c。
- `x = x * x`：先用旧的 x 算出右边，再把结果贴回 x。

- 比较 `print(x)` 和 `print("x")`，一个取变量的值，一个显示字母。

## 示例

如果程序是

```python
print("a")
print(1, 2)
```

答案就写成两行：

```
a
1 2
```

## 约束

- 只写程序的输出，不要写代码。
- 按打印顺序，一个 `print` 一行。
- 行尾空格和末尾多余的空行不影响判定。
