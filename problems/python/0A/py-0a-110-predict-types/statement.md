## 题目

读题目给出的程序，写出它运行后打印的**全部内容**。

这题想让你注意：
- 两个字符串相加是**拼接**，不是算术。
- `int(...)` 把字符串变成整数，`str(...)` 把数字变成字符串。
- `int(3.9)` 直接去掉小数部分，不是四舍五入。

- 比较 `int(7.9)` 和 `round(7.9)`：前者截去小数，后者取最近的整数 8。请预测程序里 int 那一行；也可以在课的示例编辑框里运行两种写法。

## 示例

如果程序是

```python
print("a")
print(1, 2)
```

答案就写成两行：

```
a
1 2
```

## 约束

- 只写程序的输出，不要写代码。
- 按打印顺序，一个 `print` 一行。
- 行尾空格和末尾多余的空行不影响判定。
