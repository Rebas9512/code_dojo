## 题目

读题目给出的程序，写出它运行后打印的**全部内容**。

这题想让你注意：
- `pop()` 删除并**返回**最后一个元素；`pop(0)` 删除并返回第一个。
- `insert(i, x)` 把 x 插到下标 i，后面的元素往后挪。
- `remove(x)` 按值删除第一个等于 x 的元素。

## 示例

如果程序是

```python
print("a")
print(1, 2)
```

答案就写成两行：

```
a
1 2
```

## 约束

- 只写程序的输出，不要写代码。
- 按打印顺序，一个 `print` 一行。
- 行尾空格和末尾多余的空行不影响判定。
