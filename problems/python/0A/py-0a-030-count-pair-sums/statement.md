## 题目

在 1 到 `n` 之间选两个**不同**的整数 a、b（a < b），有多少种选法使 `a + b` 恰好等于 `target`？

例如 `n = 5`、`target = 6`：(1, 5) 和 (2, 4) 两种；(3, 3) 不算，因为两个数要不同。

用两层循环：外层枚举 a，内层只枚举比 a 大的 b。

## 示例

**示例 1**

```
输入：n = 5, target = 6
输出：2
```

**示例 2**

```
输入：n = 4, target = 5
输出：2
```

## 约束

- `0 <= n <= 300`
- `0 <= target <= 1000`
