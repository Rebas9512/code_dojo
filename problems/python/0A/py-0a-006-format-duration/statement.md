## 题目

把总分钟数 `total_minutes` 转成 `"XhYmin"` 形式的字符串（h 表示小时，min 表示分钟，均为小写），例如 125 分钟 → `"2h5min"`。

编辑器里的代码已经算好了小时数和分钟数。把 `____` 换成一个 **f-string**，返回要求的字符串。

## 示例

**示例 1**

```
输入：total_minutes = 125
输出："2h5min"
```

**示例 2**

```
输入：total_minutes = 60
输出："1h0min"
```

## 约束

- `0 <= total_minutes <= 10^5`
- 分钟数为 0 时也要写出来，如 `"1h0min"`。
