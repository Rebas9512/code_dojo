## 题目

把总分钟数 `total_minutes` 转成 `"X小时Y分钟"` 形式的字符串，例如 125 分钟 → `"2小时5分钟"`。

编辑器里的代码已经算好了小时数和分钟数。把 `____` 换成一个 **f-string**，返回要求的字符串。

## 示例

**示例 1**

```
输入：total_minutes = 125
输出："2小时5分钟"
```

**示例 2**

```
输入：total_minutes = 60
输出："1小时0分钟"
```

## 约束

- `0 <= total_minutes <= 10^5`
- 分钟数为 0 时也要写出来，如 `"1小时0分钟"`。
