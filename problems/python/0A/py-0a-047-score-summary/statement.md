## 题目

给一个非空的成绩列表 `scores`，返回形如 `"最高90 最低70 平均80.0"` 的字符串：
最高分、最低分和平均分，平均分保留 1 位小数。

内置函数 `max(nums)`、`min(nums)`、`sum(nums)`、`len(nums)` 可以直接作用在列表上；
f-string 里 `{x:.1f}` 表示保留 1 位小数。

## 示例

**示例 1**

```
输入：scores = [90, 80, 70]
输出："最高90 最低70 平均80.0"
```

**示例 2**

```
输入：scores = [100]
输出："最高100 最低100 平均100.0"
```

## 约束

- `1 <= len(scores) <= 1000`
- `0 <= scores[i] <= 100`
