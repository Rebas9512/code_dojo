## 题目

把名字与分数按位置配对，只取配得上的部分。分数降序，同分按英文名字升序。返回 (名次, 名字, 分数) 的列表，名次从 1 开始，依次编号。结果里的元组显示为列表。

## 示例

**示例 1**

```text
输入：names = ['zoe', 'amy', 'lee'], scores = [5, 5, 9]
输出：[[1, 'lee', 9], [2, 'amy', 5], [3, 'zoe', 5]]
```

**示例 2**

```text
输入：names = ['t', 'u'], scores = [-1]
输出：[[1, 't', -1]]
```

## 约束

每列有 0–100 项，名字是非空小写英文串，分数为整数。
