## 题目

给同一份 `nums` 做两个实验。先用一遍循环把所有数相加。再让每个下标 `i` 和所有更大的下标 `j` 配对，逐对比较，数出值相同的对数。

在第一段之前、两段之间、第二段之后各读一次 `time.perf_counter()`，用 `print` 打印两段各自的秒数。返回 `[总和, 相等对数]`；判题只比较这两个整数。做完后打开「课」，运行 1000、2000、4000 项的示例，观察输入翻倍时哪段耗时增长更快。

## 示例

**示例 1**

```text
输入：nums = [3, 1, 3, 3]
输出：[10, 3]
```

值为 3 的位置是 0、2、3，组成 (0, 2)、(0, 3)、(2, 3) 三对。

**示例 2**

```text
输入：nums = [-2, 2]
输出：[0, 0]
```

## 约束

提交用例中有 0 至 1000 个整数，单个用例时限 2000 毫秒。空列表的总和和对数均为 0。
