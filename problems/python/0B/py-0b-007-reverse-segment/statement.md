## 题目

实现 `reverse_part`。把 `nums` 从下标 `left` 到 `right` 的一段就地倒过来，两端都包含，其余位置保持原样。保留起始代码中的 `run_case`，它会交回调用后的原列表，供你核对结果。

## 示例

**示例 1**

```text
输入：nums = [8, 2, 5, 7, 3], left = 1, right = 3
输出：[8, 7, 5, 2, 3]
```

**示例 2**

```text
输入：nums = [4, 9], left = 0, right = 1
输出：[9, 4]
```

## 约束

列表有 1 至 1000 个整数，0 ≤ left ≤ right < 列表长度。只使用常数个额外变量。
