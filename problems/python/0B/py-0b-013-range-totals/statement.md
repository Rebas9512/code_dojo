## 题目

`nums` 是每天的收支，收入为正，支出为负。每条查询 `[left, right]` 想知道从 `left` 到 `right` 这几天的净收入，两个端点都算。建一张前缀和表，再按提问顺序返回每次查询的结果。

## 示例

**示例 1**

```text
输入：nums = [4, -2, 3], queries = [[1, 2], [0, 2]]
输出：[1, 5]
```

**示例 2**

```text
输入：nums = [-3], queries = [[0, 0]]
输出：[-3]
```

## 约束

有 0 至 1000 条整数收支、0 至 1000 条查询；每条查询满足 0 ≤ left ≤ right < 天数。没有数据时也没有查询。
