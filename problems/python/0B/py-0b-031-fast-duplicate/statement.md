## 题目

实现 `has_duplicate(badges)`。只要两个不同位置上出现相同的编号，就返回 `True`；否则返回 `False`。先尝试用一个列表记下看过的编号，再换成集合。打开「课」里的第二个实验，比较两种写法在同一批无重复数据上的耗时。

保留代码中的 `run_case(n, tail)`。为了方便展示长输入，它把从 0 到 n−1 的编号依次列出，再接上 `tail`，把整张列表传给你的函数。例如 `n = 3, tail = [5, 1]` 表示 `[0, 1, 2, 5, 1]`。

## 示例

**示例 1**

```text
输入：n = 3, tail = [5, 1]
输出：True
```

**示例 2**

```text
输入：n = 2, tail = [7, -1]
输出：False
```

## 约束

0 ≤ n ≤ 60000，tail 有 0 至 100 个整数。单个用例时限 2000 毫秒。需要处理连续 60000 个互不相同的编号。
