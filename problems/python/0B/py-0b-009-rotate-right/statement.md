## 题目

实现 `rotate_right`。向右轮转一步时，末项回到开头，其余项右移一格。请用三次区间反转，在原列表上完成 `k` 步；空列表保持为空。可以复用本单元的区间反转函数。保留 `run_case` 来显示轮转后的原列表。

## 示例

**示例 1**

```text
输入：nums = [1, 2, 3, 4, 5], k = 2
输出：[4, 5, 1, 2, 3]
```

**示例 2**

```text
输入：nums = [6, 7, 8], k = 4
输出：[8, 6, 7]
```

## 约束

有 0 至 1000 个整数，0 ≤ k ≤ 10⁹。只用常数额外空间。
