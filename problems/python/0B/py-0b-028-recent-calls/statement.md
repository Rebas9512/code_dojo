## 题目

实现 `RecentCounter()`。每次调用 `ping(t)` 就在整数时刻 `t` 收到一条请求，返回从 `t - 3000` 到 `t`（含两端）一共有多少条请求。每个实例从空记录开始；后一次请求的时刻一定更大。

## 示例

**示例 1**

```text
调用：RecentCounter() → ping(2) → ping(5) → ping(3002) → ping(3006)
依次得到：[None, 1, 2, 3, 2]
```

**示例 2**

```text
调用：RecentCounter() → ping(10) → ping(8000)
依次得到：[None, 1, 1]
```

## 约束

每个实例接收 0 至 1000 次调用，1 ≤ t ≤ 10⁹，单位为毫秒。
