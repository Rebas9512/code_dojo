## 题目

实现 `compress(chars)`。从左往右把每一段连续相同字符写回原列表：先写字符，出现两次以上再逐位写十进制次数。返回写入长度；新长度之后的内容任意。保留 `run_case`，它会显示 `[长度, 原列表的有效前缀]`。

## 示例

**示例 1**

```text
输入：chars = ["a", "a", "b", "a", "a"]
输出：[5, ["a", "2", "b", "a", "2"]]
```

两段 a 被 b 隔开，需要分别记录。

**示例 2**

```text
输入：chars = ["x", "x", "x", "x", "x", "x", "x", "x", "x", "x", "x", "x"]
输出：[3, ["x", "1", "2"]]
```

## 约束

有 0 至 2000 个字符，每项是单个英文字母、数字或标点。原地读写，不另建整份结果列表。
