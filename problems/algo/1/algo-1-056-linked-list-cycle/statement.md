## 题目

判断从 head 反复走 next 是否会再次走到同一个节点，返回布尔值。样例给出节点值和 pos，pos 是尾节点连回的下标，-1 表示尾端接 None。适配代码先连好箭头，你的函数只接收 head。

在起始代码中实现 `has_cycle`。下方的 `run_case` 负责准备输入或读取调用后的状态，提交时请保留。

## 示例

**示例 1**

```text
输入 [5,1,-2,5], 1
结果 true
```

尾部虽然也存 5，但 pos=1 表示它连回的是下标 1 的节点，以后会再次经过它。

**示例 2**

```text
输入 [7,7,7], -1
结果 false
```

## 约束

0 至 10 000 个节点；pos 为 -1 或有效下标。目标 O(n) 时间、O(1) 额外空间（不计装配用例）。
