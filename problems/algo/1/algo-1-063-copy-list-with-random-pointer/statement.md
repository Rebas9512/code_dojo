## 题目

每个节点有 val、next 和 random；random 可以指向本链任意节点或 None。创建全新的节点，复制所有值和两种连接，返回副本的头。不能让副本引用原节点或改变原链。输入分为值列表和 random 目标下标列表；结果逐节点展示 [值, 目标下标]，null 表示空。起始代码提供 Node(val) 构造器。

在起始代码中实现 `copy_random_list`。下方的 `run_case` 负责准备输入或读取调用后的状态，提交时请保留。

## 示例

**示例 1**

```text
输入 [6,6,2], [2,null,0]
结果 [[6,2],[6,null],[2,0]]
```

副本第一格的 random 要跳到副本第三格；指向原链第三格虽然读到相同值，仍然错误。

**示例 2**

```text
输入 [4], [0]
结果 [[4,0]]
```

## 约束

0 至 1000 个节点，节点值可以重复。
