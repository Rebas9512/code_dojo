## 题目

把所有不等于 val 的元素放到 nums 的前 k 个位置，返回 k。保留元素可重排，后面的内容任意。样例的结果显示 [k, 前 k 项]，方便看出原地修改的效果。

在起始代码中实现 `remove_element`。下方的 `run_case` 负责准备输入或读取调用后的状态，提交时请保留。

## 示例

**示例 1**

```text
输入 [7,3,7,2], 7
结果 [2,[3,2]]
```

保留 3 和 2 共两项。写成 [2, 3] 也可以，只检查有效的前两项。

**示例 2**

```text
输入 [4,4], 4
结果 [0,[]]
```

## 约束

0 至 100 个元素，元素为 0 至 50 的整数，val 为 0 至 100 的整数。只用常数额外空间。
