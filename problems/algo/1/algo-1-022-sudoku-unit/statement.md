## 题目

检查一次落笔：board[r][c] 已填数字，周围还有没有与它相同的数字？只检查同一行、同一列、同一个 3×3 宫，忽略格子自己。有冲突返回 True。

## 示例

**示例 1**

```text
输入 [["8",".",".",".",".",".",".",".","."],[".",".",".",".",".",".",".",".","."],[".",".","8",".",".",".",".",".","."],[".",".",".",".",".",".",".",".","."],[".",".",".",".",".",".",".",".","."],[".",".",".",".",".",".",".",".","."],[".",".",".",".",".",".",".",".","."],[".",".",".",".",".",".",".",".","."],[".",".",".",".",".",".",".",".","."]], 2, 2
结果 true
```

(2, 2) 与 (0, 0) 不同行也不同列，但在左上角同一个宫里。

**示例 2**

```text
输入 [[".",".",".",".",".",".",".",".","."],[".",".",".",".",".",".",".",".","."],[".",".","8",".",".",".",".",".","."],[".",".",".","8",".",".",".",".","."],[".",".",".",".",".",".",".",".","."],[".",".",".",".",".",".",".",".","."],[".",".",".",".",".",".",".",".","."],[".",".",".",".",".",".",".",".","."],[".",".",".",".",".",".",".",".","."]], 2, 2
结果 false
```

## 约束

board 是 9×9 字符矩阵。空格用点号，其余为字符 1 至 9。r、c 从 0 起。
