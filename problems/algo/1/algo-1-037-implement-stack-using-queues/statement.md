## 题目

实现 MyStack()：push(x) 压入整数，无返回值；pop() 取走并返回最近压入的数；top() 只查看这个数；empty() 判断是否为空。内部只允许用队列的队尾入队、队首出队或查看队首、取长度与判空。

样例里的操作、参数、结果按列一一对应。第一项建立对象，同一个用例的后续操作都作用在它上面。null 表示该步没有返回值。

## 示例

**示例 1**

```text
操作 ["MyStack","push","push","pop","top"]
参数 [[],[4],[7],[],[]]
结果 [null,null,null,7,4]
```

7 后进，pop 取走它，再看栈顶便回到了 4。

**示例 2**

```text
操作 ["MyStack","empty"]
参数 [[],[]]
结果 [null,true]
```

## 约束

至多 100 次操作，pop 和 top 调用时栈非空。
