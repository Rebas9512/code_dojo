## 题目

初始 n 个编号各自成组。按顺序处理 [操作,a,b]，join 把两组合并，ask 查询当前是否同组。仅将每次查询的布尔结果按顺序交回。

补全起始代码中的 `____`。

## 示例

**示例 1**

```text
输入 4, [["join",1,2],["join",3,1],["ask",3,2],["ask",0,1]]
结果 [true,false]
```

3 经 1 与 2 相通，孤立的 0 与 1 仍不相通。

**示例 2**

```text
输入 2, [["ask",1,1],["ask",1,0]]
结果 [true,false]
```

## 约束

1 ≤ n ≤ 20 000，编号从 0 数，最多 40 000 次操作。
