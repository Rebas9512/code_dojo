## 题目

在原来的节点上改线，按根、左、右的访问顺序串成右向链，每个左孩子清空。函数不用返回值，判题沿右指针读取。

示例把树按层写成数组，null 留出缺失的孩子。函数收到的是 TreeNode 节点，空树是 None。

在起始代码中实现 `flatten`，保留随附的 `run_case` 用于判题。

## 示例

**示例 1**

```text
输入 [8,3,12,null,5,10]
结果 [8,3,5,12,10]
```

按先根次序得到 8、3、5、12、10，把这五个原节点依次接到右边。

**示例 2**

```text
输入 [-2,null,4]
结果 [-2,4]
```

## 约束

节点数为 0 至 10 000，节点值为整数。
