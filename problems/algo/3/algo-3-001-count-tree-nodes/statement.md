## 题目

先用 TreeNode(8, TreeNode(3), TreeNode(12)) 搭一棵树试算，再补全递归，让函数对传入的任意树返回节点总数。每个实际存在的节点计一次。

示例把树按层写成数组，null 留出缺失的孩子。函数收到的是 TreeNode 节点，空树是 None。

补全起始代码中的 `____`。

## 示例

**示例 1**

```text
输入 [8,3,12,null,5,10]
结果 5
```

根 8 的两侧分别有两个节点，加上根本身一共五个。

**示例 2**

```text
输入 [-2,null,4]
结果 2
```

## 约束

节点数为 0 至 10 000，节点值为整数。
