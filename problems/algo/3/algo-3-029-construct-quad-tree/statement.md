## 题目

把方形区域按左上、右上、左下、右下等分。同色区域存一个叶子，杂色区域存四个孩子。返回 Node 根；节点构造器随题提供。示例按层列出 [是否叶子, 颜色]；非叶颜色任选 0 或 1，缺孩子用 null。

在起始代码中实现 `construct`，保留随附的 `run_case` 用于判题。

## 示例

**示例 1**

```text
输入 [[1,0],[0,1]]
结果 [[0,0],[1,1],[1,0],[1,0],[1,1]]
```

整个区域杂色，四个单位方格依左上、右上、左下、右下读到 1、0、0、1。

**示例 2**

```text
输入 [[0,0],[0,0]]
结果 [[1,0]]
```

## 约束

边长是 1 至 64 之间的 2 的幂，格子只含 0 或 1。
