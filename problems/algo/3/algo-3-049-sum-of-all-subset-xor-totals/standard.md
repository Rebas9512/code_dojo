## 思路

每到一个下标，都可以跳过它，也可以把它的数异或到当前值里。走到末尾就把这个子集的异或值交回，两个分支的和便覆盖了当前位置的全部取法。

## 复杂度

设 n 为读数个数。按题中整数范围，每次异或花常数时间，共有 2ⁿ 个叶子，时间 O(2ⁿ)，额外空间 O(n) 用于递归。

## 写法要点

- 随路径携带异或值，叶子处可以直接返回。保存所有子集再逐个重算异或会重复处理它们的公共前缀。

## 进阶写法

对于某个出现过的二进制位，挑一个该位为 1 的读数，把不含它的每个子集与加入它后的子集配对，每对恰有一个异或值在该位为 1。只求总和时，把所有读数按位或，再乘每位贡献的次数 2ⁿ⁻¹ 即可，题中整数范围下时间 O(n)，额外空间 O(1)。

```python
def subset_xor_sum(nums: list[int]) -> int:
    bits = 0
    for value in nums:
        bits |= value
    return bits * (1 << (len(nums) - 1))
```
