## 题目

这里的 [a,b] 是从先修课 a 指向后续课 b 的箭头。对于每个查询 [u,v]，回答能否从 u 沿一条或多条依赖走到 v，按查询顺序返回布尔列表。

## 示例

**示例 1**

```text
输入 4, [[0,1],[1,2]], [[0,2],[2,0],[0,3]]
结果 [true,false,false]
```

0→1→2 说明 0 是 2 的间接先修，反方向和去往孤立点 3 都走不通。

**示例 2**

```text
输入 2, [], [[0,1]]
结果 [false]
```

## 约束

2 至 100 门课，依赖无环，查询两端不同，查询数不超过 10 000。
