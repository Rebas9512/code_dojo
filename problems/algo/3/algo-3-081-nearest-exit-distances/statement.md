## 题目

平面图用 -1 表示墙、0 表示出口、2147483647 表示空位。每步走到一格上下左右相邻的非墙位置。原地把每个可达空位填成其到最近出口的步数，够不到出口的空位保留原数。判题读取修改后的网格。

在起始代码中实现 `fill_exits`，保留随附的 `run_case` 用于判题。

## 示例

**示例 1**

```text
输入 [[0,2147483647,2147483647,2147483647,0]]
结果 [[0,1,2,1,0]]
```

两个出口同时向内推进，中间空位走两步就能到任一出口。

**示例 2**

```text
输入 [[0,-1,2147483647],[2147483647,-1,2147483647]]
结果 [[0,-1,2147483647],[1,-1,2147483647]]
```

## 约束

1 至 250 行、1 至 250 列。
