## 题目

从严格二叉搜索树里查找 key。命中时返回该节点为根的整棵子树，找不到返回 None。

示例把树按层写成数组，null 留出缺失的孩子。函数收到的是 TreeNode 节点，空树是 None。

先运行起始代码，观察样例中哪一项与预期不符，再修正它。

## 示例

**示例 1**

```text
输入 [8,3,12,null,5,10], 3
结果 [3,null,5]
```

从 8 向左就命中 3，返回的子树还带着 3 的右孩子 5。

**示例 2**

```text
输入 [7,3,11,2,5,9,13], 1
结果 []
```

## 约束

节点数为 0 至 10 000，节点值为整数。
