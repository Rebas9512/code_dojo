## 题目

从给定节点深复制整张连通无向图。新节点的值、邻居关系与原图一致，两张图没有共用节点。Node 提供 val 和 neighbors。输入输出用按节点值排列的邻接表展示，空图传 None。

在起始代码中实现 `clone`，保留随附的 `run_case` 用于判题。

## 示例

**示例 1**

```text
输入 [[2,3],[1,3],[1,2]]
结果 [[2,3],[1,3],[1,2]]
```

三个节点互相相连，副本也应能顺着两条不同路径认回同一个新节点。

**示例 2**

```text
输入 [[2],[1]]
结果 [[2],[1]]
```

## 约束

至多 100 个节点，编号从 1 起连续；无重边、自环。
