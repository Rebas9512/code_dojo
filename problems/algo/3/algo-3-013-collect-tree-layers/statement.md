## 题目

把树一层层读出来，返回每层打印的值，从左往右。同一层放进同一行列表，方便自动核对。

示例把树按层写成数组，null 留出缺失的孩子。函数收到的是 TreeNode 节点，空树是 None。

补全起始代码中的 `____`。

## 示例

**示例 1**

```text
输入 [8,3,12,null,5,10]
结果 [[8],[3,12],[5,10]]
```

根独占第一层，3、12 是第二层，它们的非空孩子 5、10 放在第三层。

**示例 2**

```text
输入 [-2,null,4]
结果 [[-2],[4]]
```

## 约束

节点数为 0 至 10 000，节点值为整数。
