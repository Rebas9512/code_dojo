## 题目

能否在 root 中选到一个节点，使从它开始的整棵子树与样本 sub 完全相同？后代不能截掉。

示例把树按层写成数组，null 留出缺失的孩子。函数收到的是 TreeNode 节点，空树是 None。

## 示例

**示例 1**

```text
输入 [8,3,12,null,5,10], [3,null,5]
结果 true
```

节点 3 没有左孩子，右孩子是 5，它下面的整棵树和样本一致。

**示例 2**

```text
输入 [8,3,12,null,5,10], [3]
结果 false
```

## 约束

两棵树均非空，主树最多 3 000 个节点，样本最多 1 000 个。
