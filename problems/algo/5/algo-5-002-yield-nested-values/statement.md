## 题目

实现生成器 flatten，从左至右穿过任意层列表，逐个 yield 其中的整数。样例中的第二个参数是最多读取的项数。读到上限就停止；空列表没有输出。

请实现 `flatten`。起始代码的 `run_case` 负责转换样例和读取结果，提交时保留它。

补全起始代码中标为 `____` 的位置。

## 示例

**示例 1**

```text
输入 [[],[2,[0]],9], 2
结果 [2,0]
```

先打开空列表，再打开装有 2 和 0 的列表；取两项后暂停。

**示例 2**

```text
输入 [3,[1]], 0
结果 []
```

## 约束

总格数至多 50 000，深度至多 100，读取上限非负。
