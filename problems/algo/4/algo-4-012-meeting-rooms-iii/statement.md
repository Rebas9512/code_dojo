## 题目

房间编号从 0 到 n−1。按原定开始时间安排会议，优先给编号最小的空房。全满时等最早腾出的房间，同刻仍选小编号。推迟只平移开始与结束，时长不变。返回接待次数最多的房间编号，并列取最小。

## 示例

**示例 1**

```text
输入 2, [[0,7],[1,3],[2,5]]
结果 1
```

最先两场分给 0、1。第 2 时刻要开的会等 1 号在时刻 3 腾出，1 号共两场。

**示例 2**

```text
输入 2, [[1,4],[0,4],[3,9]]
结果 0
```

## 约束

1 ≤ n ≤ 100，1 至 100 000 场会议，原定开始时间各异，0 ≤ 开始 < 结束 ≤ 500 000。
