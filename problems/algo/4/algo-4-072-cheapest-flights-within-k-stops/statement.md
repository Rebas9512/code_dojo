## 题目

城市编号从 0 到 n−1，每项 [u,v,price] 是单程航班。最多可在 k 个中间城市转机，即最多飞 k+1 段。返回从 src 到 dst 的最低总价，没有这样的行程返回 −1。

## 示例

**示例 1**

```text
输入 4, [[0,1,2],[1,2,2],[2,3,2],[0,2,9]], 0, 3, 1
结果 11
```

票价 2+2+2 需转机两次，限一次只能选 0→2→3，共 11。

**示例 2**

```text
输入 3, [[0,1,2],[1,2,1]], 0, 2, 0
结果 -1
```

## 约束

2 ≤ n ≤ 100，0 ≤ k < n，起点与终点不同。票价 1 至 10 000，同一有向城市对最多一班且没有自环。
