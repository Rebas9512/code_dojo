## 题目

0 表示可落脚的格子，1 表示封闭。起点是第一个 0。在 i 可跳到 i+low 至 i+high 中任一开放格。判断能否到最后一格。

起始代码在踏板已经超出跳跃范围后仍会把它当作来路。运行第二个样例，修正可达起点的数量。

## 示例

**示例 1**

```text
输入 "010010", 2, 3
结果 true
```

从位置 0 跳到 2，再跨三格到 5。

**示例 2**

```text
输入 "01110", 1, 3
结果 false
```

## 约束

字符串长 2 至 100 000，s[0] 为 0，1 ≤ low ≤ high < 长度。
