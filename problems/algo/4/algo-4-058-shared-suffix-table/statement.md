## 题目

给出两串文字，返回 (len(a)+1) 行、(len(b)+1) 列的表。第 i 行第 j 列写 a 的前 i 个字符和 b 的前 j 个字符共有的最长连续结尾长度。第 0 行或列对应空串。

把起始代码中的 `____` 补全。

## 示例

**示例 1**

```text
输入 "ab", "cb"
结果 [[0,0,0],[0,0,0],[0,0,1]]
```

ab 和 cb 都以 b 结束，倒数第二个字符不同，所以右下角是 1。

**示例 2**

```text
输入 "aa", "aa"
结果 [[0,0,0],[0,1,1],[0,1,2]]
```

## 约束

两串各长 0 至 120，只含小写英文字母。
