## 题目

把 n×n 矩阵顺时针旋转 90°。修改传入的矩阵本身，无需返回值，不另建同尺寸矩阵。

在起始代码中完成 `rotate_image`，保留下方的 `run_case`。它负责调用你的代码并把结果交给判题器。

## 示例

**示例 1**

```text
输入 [[2,7],[1,9]]
结果 [[1,2],[9,7]]
```

左下角的 1 转到左上角，原来的第一行 2、7 成为最右列。

**示例 2**

```text
输入 [[3,5,7],[1,2,4],[8,6,9]]
结果 [[8,1,3],[6,2,5],[9,4,7]]
```

## 约束

1 ≤ n ≤ 20。使用 O(1) 额外空间。
