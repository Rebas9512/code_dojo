## 题目

实现 NumMatrix(matrix) 保存一张不变的整数网格。sumRegion(row1,col1,row2,col2) 返回从左上角到右下角所围矩形的总和，坐标从 0 起，两角都在矩形中。

每组操作都从新对象开始。示例里的操作、参数和结果按位置对应，null 表示这一步没有返回值。

## 示例

**示例 1**

```text
操作 ["NumMatrix","sumRegion","sumRegion"]
参数 [[[[3,-2],[5,4]]],[0,0,1,1],[1,1,1,1]]
结果 [null,10,4]
```

整块合计为 10；从 (1,1) 到 (1,1) 只取一格，读到 4。

**示例 2**

```text
操作 ["NumMatrix","sumRegion"]
参数 [[[[2,-3,1]]],[0,1,0,2]]
结果 [null,-2]
```

## 约束

行数和列数均为 1 至 200；查询次数最多 10 000，每个矩形的两角合法。每次查询 O(1)。
