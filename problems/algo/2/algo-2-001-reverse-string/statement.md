## 题目

原地翻转字符列表 chars。直接改同一列牌，函数无需返回值。

在起始代码中完成 `reverse_string`，保留下方的 `run_case`。它负责调用你的代码并把结果交给判题器。

## 示例

**示例 1**

```text
输入 ["l","a","m","p"]
结果 ["p","m","a","l"]
```

最外的 l 和 p 对换，再交换中间的 a 和 m。

**示例 2**

```text
输入 ["A","a","!"]
结果 ["!","a","A"]
```

## 约束

1 至 100 000 个可打印 ASCII 字符，额外空间 O(1)。
