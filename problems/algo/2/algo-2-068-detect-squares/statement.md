## 题目

实现 DetectSquares()。add([x,y]) 登记一个点，同坐标可以多次登记。count([x,y]) 用给定点作一个角，从登记点中选另外三个，统计能拼成多少个边长为正、边平行于坐标轴的正方形。不同登记记录分别计数，查询点无需登记。

每组操作都从新对象开始。示例里的操作、参数和结果按位置对应，null 表示这一步没有返回值。

## 示例

**示例 1**

```text
操作 ["DetectSquares","add","add","add","count","add","count"]
参数 [[],[[2,5]],[[5,2]],[[5,5]],[[2,2]],[[5,5]],[[2,2]]]
结果 [null,null,null,null,1,null,2]
```

角 (5,5) 第二次登记后，同一个形状可以选两套不同的点。

**示例 2**

```text
操作 ["DetectSquares","count","add","count"]
参数 [[],[[0,0]],[[0,0]],[[0,0]]]
结果 [null,0,null,0]
```

## 约束

坐标均为 0 至 1000 的整数，add 和 count 合计最多 3000 次。
