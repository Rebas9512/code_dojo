## 题目

nums1 的前 m 格与 nums2 的 n 格分别按非降序排列。nums1 尾部另有 n 个占位零。把合并结果按非降序写回 nums1，函数无需返回值。

在起始代码中完成 `merge`，保留下方的 `run_case`。它负责调用你的代码并把结果交给判题器。

## 示例

**示例 1**

```text
输入 [-6,3,0,0], 2, [0,4], 2
结果 [-6,0,3,4]
```

原来的 -6 和 3 都是数据，占位零不参与比较。

**示例 2**

```text
输入 [0], 0, [2], 1
结果 [2]
```

## 约束

0 ≤ m,n ≤ 200，1 ≤ m+n ≤ 200。有效数据中也可以有零。
