## 题目

把 a、b 看成两排从右向左编号的二进制开关，最右格编号为 0。先手算两组样例，再补全函数，依次返回按位与、按位或、按位异或、a 左移 i 位、a 右移 i 位，以及 a 的第 i 位。

把起始代码里的 `____` 补全。

## 示例

**示例 1**

```text
输入 6, 3, 1
结果 [2,7,5,12,3,1]
```

6 是 110，3 是 011，同时点亮的只有中间格，按位与得 010，也就是 2。

**示例 2**

```text
输入 9, 5, 2
结果 [1,13,12,36,2,0]
```

## 约束

0 ≤ a,b < 2²⁰；0 ≤ i ≤ 31。每个输出用十进制整数。
