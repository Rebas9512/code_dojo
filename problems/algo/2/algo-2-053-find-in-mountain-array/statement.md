## 题目

山脉数组先严格升后严格降，两侧都非空。实现 find_mountain(target,mountain)，用 mountain.length() 取长度、mountain.get(i) 读值。返回 target 出现的最小下标，找不到返回 -1。样例列表由适配器封装，仅通过公开方法读。

在起始代码中完成 `find_mountain`，保留下方的 `run_case`。它负责调用你的代码并把结果交给判题器。

## 示例

**示例 1**

```text
输入 3, [1,3,7,5,3,0]
结果 1
```

左右山坡各有一个 3，较早的是下标 1。

**示例 2**

```text
输入 5, [2,9,6,1]
结果 -1
```

## 约束

长度 3 至 10 000；值和目标为 0 至 10⁹。每个用例最多调用 get 100 次。
