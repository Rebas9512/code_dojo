## 题目

账本 nums 不再变动。每笔查询 [left,right] 都问从下标 left 到 right 的合计，包含两端。按查询顺序返回答案。

把起始代码里的 `____` 补全。

## 示例

**示例 1**

```text
输入 [3,-8,6], [[0,1],[2,2]]
结果 [-5,6]
```

第一个查询包含 3 和 -8。第二个查询只取最后一格。

**示例 2**

```text
输入 [7], []
结果 []
```

## 约束

1 至 50 000 项，0 至 50 000 次查询；0 ≤ left ≤ right < 长度。建表 O(n)，单次查询 O(1)。
