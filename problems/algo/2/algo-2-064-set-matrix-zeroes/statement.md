## 题目

只按修改前的 matrix 判断：凡是原本有零的行和列，整行整列都改成 0。原地更新，不返回结果。请尝试 O(1) 额外空间。

在起始代码中完成 `set_zeroes`，保留下方的 `run_case`。它负责调用你的代码并把结果交给判题器。

## 示例

**示例 1**

```text
输入 [[2,0,4],[1,5,6]]
结果 [[0,0,0],[1,0,6]]
```

开始只有 (0,1) 为零，所以只清第 0 行、第 1 列。

**示例 2**

```text
输入 [[3,7],[0,4]]
结果 [[0,7],[0,0]]
```

## 约束

1 至 200 行、1 至 200 列，每行等长。
