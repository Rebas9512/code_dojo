为了让不同部分能复现同一份报告，依次做以下操作。

1. 建立一个 `np.random.default_rng(seed)`。先处理标签 0，再处理标签 1。把本类行号按文件顺序排好，调用同一生成器的 `permutation` 洗牌。
2. 本类有 `n` 行，令 `h = n // 5`。洗牌后前 `n - 2*h` 行归训练，接下来 `h` 行归验证，最后 `h` 行归测试。
3. 分别把两类的训练行、验证行、测试行拼在一起，各组内先放标签 0 再放标签 1。继续用同一个生成器，按训练、验证、测试顺序对三组各调用一次 `permutation`。返回这三组一维整数行号。

## 示例

- 标签按 `[0, 1] * 5` 排列、种子为 0 时，三组行号依次为 `[9, 6, 4, 5, 3, 8]`、`[1, 0]`、`[2, 7]`。
- 标签为 `[1, 1, 1, 0, 0, 0, 0, 0]`、种子为 7 时，依次为 `[2, 5, 1, 3, 0, 7]`、`[4]`、`[6]`。只有三人的那一类全部进入训练集。
