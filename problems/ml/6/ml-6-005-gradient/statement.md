梯度告诉训练循环每个系数该往哪个方向挪。这里求整批损失的导数，最后一个系数控制基础分。

## 签名与任务

```python
def gradient(design, labels, weights, l2):
```

令 `p = sigmoid(design @ weights)`。每位读者对线性分数的导数是 `p - labels`。把各行按特征值加权汇总，再除以样本数，得到每个系数的平均梯度。对最后一个系数之前的各项，额外加 `l2 * weights[:-1]`。按权重原顺序返回一维浮点数组。

## 示例

示例用列表表示输入的 NumPy 数组。

- `gradient([[0, 1], [2, 1]], [0, 1], [0, 0], 0)` 返回 `[-0.5, 0.0]`。
- `gradient([[1, 1]], [1], [2, -2], 0.5)` 返回 `[0.5, -0.5]`。偏置导数只来自这位读者的残差。

## 约束

设计矩阵最后一列全为 1，标签是 0 或 1，每批至少一行。骨架已提供稳定的 sigmoid。
