给运营同学一份流失名单时，需要同时说清名单里有多少人真的流失，以及实际流失的人里找回了多少。把真实标签和预测对齐后，这些数都能从四个计数算出。

## 签名与任务

```python
def classification_report(labels, predictions):
```

返回字典，键为 `confusion`、`precision`、`recall`、`f1`。混淆矩阵按真实行、预测列排列为 `[[TN, FP], [FN, TP]]`，其中 1 表示流失。精确率为 TP/(TP+FP)，召回率为 TP/(TP+FN)，F1 为 2TP/(2TP+FP+FN)。每项遇到自己的分母为 0 时取 0。

## 示例

示例用列表表示输入的 NumPy 数组。

- 真实 `[0, 0, 1]`，预测 `[1, 0, 1]`，矩阵是 `[[1, 1], [0, 1]]`。精确率 0.5，召回率 1，F1 为 2/3。
- 真实 `[1, 1, 0]`，预测 `[0, 0, 0]`，矩阵是 `[[1, 0], [2, 0]]`，三项指标都为 0。

## 约束

两个序列等长非空，元素均为 0 或 1。结果应能直接打印为 JSON，矩阵用嵌套列表和整数计数。
