训练循环把一次梯度计算接到下一次。每走一步都用更新后的系数重新预测，逐渐得到这批读者的模型。

## 签名与任务

```python
def train_model(design, labels, rate, l2, steps):
```

创建长度等于设计矩阵列数的全零浮点权重。进行 `steps` 次全批更新，每次调用已有的 `gradient(design, labels, weights, l2)`，沿负梯度方向走 `rate` 倍的距离。返回最后的一维权重数组。

## 示例

示例用列表表示输入的 NumPy 数组。

- `train_model([[0, 1], [2, 1]], [0, 1], 0.2, 0, 1)` 返回 `[0.1, 0.0]`。
- `train_model([[1], [1]], [1, 1], 0.4, 1, 2)` 返回约 `[0.3800664]`。第一步得到 0.2，第二步在 0.2 处重新算梯度。

## 约束

输入至少一行，最后一列是偏置。步数为非负整数；零步时返回初始权重。每次调用均独立从零开始。
