模型只能接收数值。给训练中见过的每个城市单留一列，让模型能按城市调整分数；再加一列常数，让每位读者都能得到同一个基础分。

## 签名与任务

```python
def design_matrix(numeric, cities, vocabulary):
```

输入标准化后的二维数值矩阵 `numeric`、同样行数的城市序列 `cities` 和有序城市词表 `vocabulary`。返回二维浮点设计矩阵，先放原数值列，然后按给定词表顺序放城市指示列，最后放全 1 偏置列。某行的城市与该列城市相等就填 1，否则填 0。

## 示例

示例用列表表示输入的 NumPy 数组。

- `design_matrix([[2], [-1]], ["rome", "oslo"], ["oslo", "rome"])` 得到 `[[2, 0, 1, 1], [-1, 1, 0, 1]]`。
- `design_matrix([[0, 3]], ["lima"], ["rome"])` 得到 `[[0, 3, 0, 1]]`。`lima` 没有对应的训练词表列。

## 约束

词表项互异。若有 d 个数值特征和 c 个词表城市，输出每行恰有 d+c+1 列。沿用传入的列序，遇到新城市时所有城市列填 0。
