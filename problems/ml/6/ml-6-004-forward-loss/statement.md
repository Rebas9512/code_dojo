线性分数要先换算成概率，才能解释一位读者有多可能流失。训练时还需要一个数衡量整批预测的误差，并给过大的特征系数一点代价。

## 签名与任务

```python
def forward_loss(design, labels, weights, l2):
```

设设计矩阵为 `design`，0/1 标签为 `labels`，系数为 `weights`，最后一项为偏置。返回 `(probabilities, loss)`。先算 `z = design @ weights`，用骨架提供的 `sigmoid(z)` 得到流失概率。

每个标签为 0 的样本贡献 `logaddexp(0, z)`，标签为 1 时贡献 `logaddexp(0, -z)`。对这些损失取样本平均，再加上 `l2 / 2 * sum(weights[:-1] ** 2)`。惩罚项独立于样本数。

## 示例

示例用列表表示输入的 NumPy 数组。

- 对 `design=[[0, 1], [2, 1]]`、标签 `[0, 1]`、全零权重及 `l2=0`，返回概率 `[0.5, 0.5]` 和损失约 `0.693147`。
- 对 `design=[[1, 1]]`、标签 `[1]`、权重 `[2, -2]`、`l2=0.5`，概率是 `[0.5]`，损失约 `1.693147`。其中惩罚贡献 1。

## 约束

输入是形状为 (n,d)、(n,)、(d,) 的数组，n、d 均为正，l2 ≥ 0。线性分数可能达到 ±1000，输出损失须有限。
