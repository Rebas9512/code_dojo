## 题目

q 为「批、查询、特征」，k 为「批、键、特征」。返回每对查询和键的原始点积，按「批、查询、键」排列。 输入已是整数张量。请用 torch.einsum 返回结果；判题会用显式张量运算逐格核对。

## 示例

`q = [[[-1, 0]], [[1, 2]]]`，`k = [[[-4, -2], [-3, -1]], [[0, 2], [1, 3]]]` → `[[[4, 3]], [[4, 7]]]`

`q = [[[0], [1]]]`，`k = [[[-2], [-1], [0]]]` → `[[[0, 0, 0], [-2, -1, 0]]]`

## 约束

q 和 k 的批数、特征数相同，查询数与键数可以不同。所有轴均非空。
