## 题目

两批都装好了。给店员一行结账结果，让她核对历史档案、成交件数和待处理的来料异常。判题时会直接备好两批仓库。

写一条查询，依次返回六个整数指标。

| 列 | 取数口径 |
| --- | --- |
| `customer_versions` | `dim_customer` 的全部历史版本数 |
| `current_customers` | `dim_customer` 中 `valid_to` 为 NULL 的行数 |
| `products` | `dim_product` 中的商品数，含未售商品 |
| `fact_rows` | `fact_sale` 的销售明细行数 |
| `units` | `fact_sale.qty` 的合计件数 |
| `quality_issues` | `sale_issues` 中的异常条数，同一来料两种原因计两条 |

## 示例

- 项目两批结账得到 `(5, 3, 4, 6, 17, 0)`。客户升档留下的旧版本也算入第一列。行号 `102` 更正后按三件计入总量。
- 单行小账本只有一名客户的一个版本、一种商品、一条一件的销售，没有异常。结果为 `(1, 1, 1, 1, 1, 0)`。

## 约束

每张表按自己的粒度统计。一张空事实表的成交件数为零；即使所有表都为空，也要返回一行六个零。表和视图已备好，本题只读。
