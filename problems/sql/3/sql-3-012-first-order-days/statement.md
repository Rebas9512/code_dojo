## 题目

先求每位买家的首单日，再按首单日统计首次下单人数。所有订单状态都算。

把编辑器里的 `____` 换成缺少的 SQL。

## 用到的表

订单表 `orders(order_id, user_id, order_date, status)` 每单一行，日期可重复。

| 2024-12-02 | 1 |
| 2024-12-15 | 1 |
| 2025-01-01 | 1 |
| 2025-01-05 | 1 |
| 2025-01-09 | 1 |
| 2025-01-20 | 1 |
| 2025-02-01 | 1 |

1 号读者之后又下了单，但只能计入 2024-12-02 的人数。

按上表的列顺序输出。行的顺序不限。
