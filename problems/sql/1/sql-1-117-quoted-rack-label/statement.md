## 题目

编辑器里的 MySQL 查询会在 PostgreSQL 上报错。把它改写成 PostgreSQL 查询，保留原稿中每个架子的汇总结果。

每个架子输出一行，`rack` 显示该组实际的架号，`total` 是这个架子上各批纸张的张数之和。

## 样例输入

`sheet_lots`

| rack | sheets |
|---|---|
| A | 3 |
| A | 4 |
| B | 7 |
| C | 2 |

## 样例结果

| rack | total |
|---|---|
| B | 7 |
| C | 2 |
| A | 7 |

A 组应显示自己的架号 A，两批合计 7 张。

按上表的列顺序输出。行序不限。
