## 题目

按城市统计下过单的不同读者人数。下过多单也只记一人，取消的订单同样表示下过单。城市未填写的记录合为一组。只列有订单的城市。

把编辑器里的 `____` 换成缺少的 SQL。

## 用到的表

书店随题提供 `buyer_orders(city, user_id)`，已给每笔订单附上买家城市和读者编号，可直接查询。城市可以是 NULL。

## 示例结果

| city | buyers |
|---|---|
| NULL | 3 |
| Beijing | 3 |
| Chengdu | 1 |
| Guangzhou | 1 |
| Hangzhou | 2 |
| Shanghai | 3 |
| Shenzhen | 2 |
| Suzhou | 1 |

样例共 8 行。

1 号读者在上海下过多单。在上海这一组，他贡献的人数仍然是 1。

按上表的列顺序输出。行的顺序不限。
