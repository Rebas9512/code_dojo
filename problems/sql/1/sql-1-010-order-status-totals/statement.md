## 题目

对每一位有订单的用户，依次输出用户编号、已送达（delivered）的订单数和已取消（cancelled）的订单数。只有其他状态的用户也保留，两列都填 0。

把编辑器里的 `____` 换成缺少的 SQL。

## 用到的表

`orders` 每行一笔订单。`user_id` 是下单人，`status` 是当前状态。

## 示例结果

| user_id | delivered_count | cancelled_count |
|---|---|---|
| 1 | 5 | 0 |
| 10 | 1 | 0 |
| 11 | 1 | 0 |
| 12 | 1 | 0 |
| 13 | 0 | 1 |
| 14 | 1 | 0 |
| 15 | 1 | 0 |
| 19 | 0 | 0 |

样例共 16 行。这里只列出其中 8 行。

19 号用户下过单，但订单状态为 shipped，所以两项计数都是 0。

按上表的列顺序输出。行的顺序不限。
