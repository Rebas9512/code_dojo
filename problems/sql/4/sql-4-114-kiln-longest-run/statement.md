## 题目

每台窑按已知日期算最长连续巡查天数，输出 kiln 和 longest。同日多次巡查算一天；并列最长也只返回一个长度。

## 样例输入

`kiln_checks`

| kiln | day |
|---|---|
| A | 2025-01-31 |
| A | 2025-02-01 |
| A | 2025-02-01 |
| A | 2025-02-04 |
| A | 2025-02-02 |
| B | 2025-02-01 |
| A | NULL |

## 样例结果

| kiln | longest |
|---|---|
| A | 3 |
| B | 1 |

A 月末与次月月初连成一段。后续日期中间有空档，要另算。

按上表的列顺序输出。行序不限。
