## 题目

每个有销售的日期输出当天日期、当日销售额、从第一天截至当天的累计销售额。按日期升序。

把编辑器里的 `____` 换成缺少的 SQL。

## 用到的表

daily_sales(day, amount) 是书店汇总好的日表，逐日合并同日各明细，排除取消订单。

## 示例结果

| day | amount | total |
|---|---|---|
| 2024-12-02 | 117 | 117 |
| 2024-12-15 | 46.8 | 163.8 |
| 2024-12-31 | 55 | 218.8 |
| 2025-01-01 | 100 | 318.8 |
| 2025-01-09 | 75.6 | 394.4 |
| 2025-01-20 | 168.9 | 563.3 |
| 2025-02-01 | 35.1 | 598.4 |
| 2025-02-14 | 62 | 660.4 |

样例共 28 行。这里只列出其中 8 行。

日表每个日期只占一行，今天的累计额等于昨天以前的总额加今天的金额。

按上表的列顺序输出。行的顺序按题目要求。
