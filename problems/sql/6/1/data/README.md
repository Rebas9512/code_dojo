# 书店月报的数据

完整月报使用 SQL 线共享的 [bookstore](../../../_db/bookstore/) 练习库。`schema.sql` 定义表和键，`seed.sql` 提供虚构的书目、作者、读者、订单和明细。原库的 33 笔订单横跨 2024 年 12 月至 2025 年 6 月。项目页的“下载数据”提供这两段 SQL，可用来运行导出的月报。

单题点“运行”时，原库会加上 `extra.sql` 的七月订单，同一张结果表能核对两段题面示例。正式提交还会在原库和三份独立的边界补丁上各判一次。每份补丁都从原库出发。

| 文件 | 新增的情境 |
| --- | --- |
| `extra.sql` | 题面公开的七月示例，含同日复购、测试单、取消单和并列畅销分类。 |
| `gaps.sql` | 只有无效订单的月份、没有明细的有效单，以及作者不详的图书。 |
| `ties.sql` | 同额明细、同名作者、并列名次后的下一名，以及同人同日多次购买。 |
| `year-end.sql` | 跨年断月、成交价为零的赠书和上月销售额为零的环比。 |

**来源和许可**　共享库由 code-dojo 原创。四份补丁为本项目手写的虚构订单，沿用仓库根 README 的许可声明，保留所有权利。数据未使用第三方订单或书目数据。
