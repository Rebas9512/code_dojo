## 题目

书店的迎新活动使用以大写 `NEW` 开头的优惠码。在订单表 `orders` 中，`order_id` 是订单号，`coupon_code` 是优惠码。找出用了迎新优惠码的订单。

起始代码中的 `~` 会检查左边的文字能否匹配右边的正则表达式。把空位换成一个带单引号的模式，让匹配从优惠码的第一个字符开始。

## 示例

书店样例中只有一笔订单符合条件：

| order_id | coupon_code |
|---|---|
| 104 | NEWYEAR |

如果遇到 `RENEW10`，其中的 `NEW` 出现在中间，这笔订单应跳过。

## 约束

- `NEW` 本身也符合条件；大小写要完全相同。没有优惠码的订单跳过。
- 输出 `order_id`、`coupon_code`，每笔符合条件的订单一行，行序不限。
