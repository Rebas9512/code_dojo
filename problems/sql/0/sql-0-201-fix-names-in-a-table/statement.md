## 题目

打印一份读者名册。每个名字的第一个字母用大写，后面的字母全用小写。结果依次显示 `user_id` 和整理后的 `name`，按编号从小到大排列。

`users` 每行是一位读者。`user_id` 是唯一编号，`name` 是登记时填写的名字。

## 示例

**users**

| user_id | name |
|---|---|
| 42 | eLI |
| 7 | q |
| 18 | MiRA |

**查询结果**

| user_id | name |
|---|---|
| 7 | Q |
| 18 | Mira |
| 42 | Eli |

18 号的 `M` 已经大写，仍要把后面的 `RA` 改成小写。7 号只有一个字母。

## 约束

- 每个名字至少有一个字母，只含 A–Z 和 a–z。
- 每个编号保留一行，即使整理后两人的名字相同。
