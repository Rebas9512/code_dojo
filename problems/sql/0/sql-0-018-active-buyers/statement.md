## 题目

找出在 2025 年 1 月 1 日到 6 月 30 日（含两端）之间下过订单的用户。已取消（`status = 'cancelled'`）的订单不算。

每个用户只列一次，按 `user_id` 从小到大排列。

用到的表（书店练习数据库）：

**orders**（订单）

| 列 | 类型 | 说明 |
|---|---|---|
| order_id | integer | 主键 |
| user_id | integer | 下单用户 |
| order_date | date | 下单日期 |
| status | text | paid / shipped / delivered / cancelled |
| coupon_code | text | 优惠码，可能为空 |

## 示例

在书店样例数据上，正确结果是：

| user_id |
|---|
| 1 |
| 2 |
| 3 |
| 5 |
| 6 |
| 7 |
| 9 |
| 10 |

（共 14 行，这里只列出前 8 行。）

## 约束

- 结果一列：`user_id`。
- 结果要按题目要求的顺序排列。
- 列名不检查，但列的个数和顺序要和要求一致。
- 提交后还会在几份隐藏数据上运行（比如多了并列、空值、边界值），只对样例凑出结果是不够的。
