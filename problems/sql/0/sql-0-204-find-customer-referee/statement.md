## 题目

书店按推荐来源分开发送邀请。2 号读者推荐来的人已经收到邀请了，这次请列出其余每位顾客的姓名 `name`。直接来店、没有推荐人的顾客也要收到。

`customer` 每行是一位顾客。`id` 是顾客自己的编号，`referee_id` 是推荐人的编号。没有推荐人时，这一格是 `NULL`。

## 示例

**customer**

| id | name | referee_id |
|---|---|---|
| 2 | 阿澄 | NULL |
| 8 | 小池 | 2 |
| 5 | 白帆 | NULL |
| 10 | 小池 | 5 |

**查询结果**

| name |
|---|
| 阿澄 |
| 白帆 |
| 小池 |

8 号和 10 号都叫小池，只有 10 号符合条件。2 号自己没有推荐人，也在这批名单里。

## 约束

- 不同顾客可以同名。每位符合条件的顾客各占一行。
- 只输出姓名，行序不限。
