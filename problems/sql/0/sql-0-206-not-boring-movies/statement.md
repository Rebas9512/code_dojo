## 题目

放映室用奇数编号的影片做周末专场，并跳过短评恰好为 `boring` 的片子。列出入选影片的编号、片名、短评和评分，评分最高的放在第一行。

`cinema` 每行是一部影片。`id` 是正整数编号，`movie` 是片名，`description` 是短评，`rating` 是评分。

## 示例

**cinema**

| id | movie | description | rating |
|---|---|---|---|
| 7 | 灯塔 | gentle | 7.6 |
| 2 | 长街 | vivid | 9.8 |
| 11 | 泊岸 | boring | 9.3 |
| 5 | 纸船 | fun | 8.4 |

**查询结果**

| id | movie | description | rating |
|---|---|---|---|
| 5 | 纸船 | fun | 8.4 |
| 7 | 灯塔 | gentle | 7.6 |

长街的评分最高，但编号是偶数。泊岸因短评被跳过。纸船与灯塔都入选，纸船在前。

## 约束

- 编号唯一，评分在 0 到 10 之间。测试数据中，入选影片的评分互不相同。
- 短评按整段文字区分大小写比较。按 `id`、`movie`、`description`、`rating` 的列顺序输出。
