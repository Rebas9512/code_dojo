## 题目

财务只核对补贴低于 1000 元或尚无补贴记录的人。按姓名、补贴金额输出。尚无记录时金额保留 NULL；实发 0 元就显示 0。

## 用到的表

`staff(staff_id, name)` 是员工清单。

`bonuses(staff_id, amount)` 每位员工最多一条，金额非空且非负。

## 样例数据

**staff**

| staff_id | name |
|---|---|
| 1 | 小杭 |
| 3 | 阿禾 |
| 5 | 叶朗 |
| 7 | 沈竹 |

**bonuses**

| staff_id | amount |
|---|---|
| 3 | 600 |
| 5 | 1000 |
| 7 | 1300 |

## 示例结果

| name | amount |
|---|---|
| 小杭 | NULL |
| 阿禾 | 600 |

样例共 2 行。

小杭尚无补贴记录，金额显示 NULL。叶朗的 1000 元刚好达到门槛，不在清单里。

按上表的列顺序输出。行的顺序不限。
