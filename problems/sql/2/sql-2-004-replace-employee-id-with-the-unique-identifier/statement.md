## 题目

每位员工都应在门禁名册上出现。按门禁号、员工姓名的列顺序输出；还没领卡的员工，门禁号留 NULL。同名员工分别保留。

## 用到的表

`staff(staff_id, name)` 是员工名册，员工号唯一。

`badges(staff_id, badge_id)` 是领卡记录，每人最多一张，卡号非空。

## 样例数据

**staff**

| staff_id | name |
|---|---|
| 2 | 杨青 |
| 3 | 阿索 |
| 5 | 杨青 |

**badges**

| staff_id | badge_id |
|---|---|
| 5 | 702 |
| 3 | 910 |

## 示例结果

| badge_id | name |
|---|---|
| NULL | 杨青 |
| 702 | 杨青 |
| 910 | 阿索 |

样例共 3 行。

两位杨青分别是 2 号和 5 号员工。只有 5 号领到了 702 号卡。

按上表的列顺序输出。行的顺序不限。
