## 题目

输出所有读者的编号，以及买入 fiction、scifi、kids 的册数，按此顺序放三列。没有买过的格子填 0；其余分类忽略。

把编辑器里的 `____` 换成缺少的 SQL。

## 用到的表

users(user_id) 是完整名册，book_purchases(user_id,category,quantity) 只列未取消的订单明细，quantity 为册数。

## 示例结果

| user_id | fiction | scifi | kids |
|---|---|---|---|
| 1 | 0 | 3 | 0 |
| 10 | 0 | 0 | 0 |
| 11 | 0 | 0 | 0 |
| 12 | 0 | 2 | 0 |
| 13 | 0 | 0 | 0 |
| 14 | 0 | 0 | 0 |
| 15 | 0 | 0 | 3 |
| 16 | 0 | 0 | 0 |

样例共 20 行。这里只列出其中 8 行。

从未下单的 16 号也有一行，三列均为 0。

按上表的列顺序输出。行的顺序不限。
