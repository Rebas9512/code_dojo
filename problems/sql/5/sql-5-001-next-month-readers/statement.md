## 题目

按注册所在的自然月分批。输出批次月初、注册人数、次月登录过的人数及留存率（0 到 1）。每人只算一次，没有返回者的批次也列出，全部批次均已观察满次月。

把编辑器里的 `____` 换成缺少的 SQL。

## 用到的表

registration_months(user_id, cohort, next_start, next_end) 已给出本月、下月和下下月的月初。reader_logins(login_id, user_id, logged_on) 每次登录一行，同人同日可重复。

## 示例结果

| cohort | readers | returned | rate |
|---|---|---|---|
| 2024-11-01 | 2 | 2 | 1 |
| 2024-12-01 | 2 | 0 | 0 |
| 2025-01-01 | 3 | 1 | 0.33333333333333333333 |
| 2025-02-01 | 3 | 1 | 0.33333333333333333333 |
| 2025-03-01 | 3 | 0 | 0 |
| 2025-04-01 | 2 | 0 | 0 |
| 2025-05-01 | 2 | 0 | 0 |
| 2025-06-01 | 3 | 0 | 0 |

样例共 8 行。

11 月注册的 1、2 号都在 12 月登录，批次有 2 人，留存率为 1。

按上表的列顺序输出。行的顺序不限。
