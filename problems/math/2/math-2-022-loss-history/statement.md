## 题目

把订量 x 看作连续数，损失为 (x−target)²。返回起点以及每次梯度下降后的损失。rate 固定，一共更新 steps 次。

## 示例

- `loss_history(5, 3, 0.25, 2)` → `[4, 1, 0.25]`
- `loss_history(5, 3, 1.5, 2)` → `[4, 16, 64]`

第一组订量依次是 5、4、3.5。与目标 3 的差平方后得到 4、1、0.25。

## 约束

0 ≤ x、target ≤ 30，0 ≤ rate ≤ 1.5，0 ≤ steps ≤ 8。允许越过目标。 返回计算值即可，示例中的小数可为近似值。
