# 67-memory-controls：网页里的"助教记忆"开关和清空

## 背景
用户 2026-11-24 拍板按 `docs/tutor-memory.md`（64c）做助教长期记忆，并要求"有一些功能上的优化更新记得就是除了mac以外别的系统也能用上"。66 已经做好后端：`GET/PUT /api/memory/settings`、`POST /api/memory/clear`（响应格式见 `docs/README.md` 的 API 部分和 `server/app/main.py`）。

设计文档"入口"一条写了桌面设置窗口和网页两处。**这次只做网页**：网页跟着更新包走，Windows、Linux、macOS 的桌面版和浏览器版都不用重装就能用上。桌面原生设置窗口（`desktop/`）不改。

同时在跑的任务 68 改 `server/`，你只改 `web/`，另外可以改 `docs/README.md` 里讲网页设置的一两句、`docs/tutor-memory.md` 的"入口"一条（改成现状：只在网页）。

## 要做的事
1. 按设计文档，在「今日计划」现有的每日上限设置旁边放"允许助教记忆"开关和"清空记忆"。清空要再确认一次，确认文案用设计文档里的那句。
2. 命令面板（Ctrl+Shift+P）加"开启 / 关闭助教记忆"一条，方便在做题页切换。
3. `api.ts` 加对应调用。开关切换后，正在打开的助教面板不需要做任何显示；没有记忆页面、没有回执。
4. 界面遵守 `.impeccable.md`：字少、安静，深浅两套主题都看得清，键盘可达。

## 这次不做
- 记忆页面、列出记忆条目、编辑记忆。
- `desktop/`、`server/`、`bootstrap/`。

## 验收标准
- `cd web && npm run build` 通过，`web/tests` 里已有的测试照常过。
- 起测试实例：后端 8017（`CODE_DOJO_AI_PROVIDER=off`，独立数据目录），前端 5187。浏览器里走一遍：默认开 → 关 → 刷新仍是关 → 开 → 清空（确认框取消一次、确认一次）。截图放 `{RUN_DIR}/`（深色、浅色各一张）。
- 结束关掉自己起的进程。
