# 17 · 进阶线「数学（用代码学）」：技能图 + 课 + 题，线改成 active

## 背景

用户 2026-11-22 说："到后面进阶的内容我也想做一些 比如数据科学类的 数据操作，模型训练，tensor操作，手搓大语言模型之类的"。

设计在 `docs/README.md` 2b 节。数学线是这几条进阶线的地基：
- 张量线和机器学习线都把它列为前置；
- 用户按零基础设计，学机器学习之前，必须先把要用到的数学补上。

这条线的 runtime 是 `python`，用普通 Python 判题镜像，**不用 numpy**。全用纯 Python（列表、循环、函数、`math` 模块、`random` 模块）来算，目的是让学习者亲手算一遍，知道每个数是怎么来的。numpy 留给数据处理线。

**零基础**：学习者不一定记得中学数学。每个概念都要从"它是什么、为什么要它"讲起：
- 先给具体数字的例子，再给公式；
- 公式旁边配一段几行的 Python 代码。

不推导、不证明，用数值实验代替证明。比如"导数"用"把 h 取得越来越小，看差商收敛到哪"来理解。

**并行**：12（算法阶段 3）、05c（SQL）、13（平台：登录）可能同时在跑，先读 `codex/PLAN.md`。

## 要做的事

### 1. 技能图（`problems/math/skills.yaml`）

约 20–25 个技能，前缀 `math.`，分在现有 3 个阶段里，每个阶段再分 2–4 个组。组名写进 `track.yaml` 的 `units`。下面是参考范围，可以调整，写进报告：

- **阶段 1 向量和矩阵**：
  - 向量就是一串数（用列表表示）
  - 向量加减和数乘
  - 点积，以及它的意思："对应相乘再相加"、加权求和
  - 向量长度和距离
  - 矩阵是"列表的列表"：行和列
  - 矩阵乘向量
  - 矩阵乘矩阵（形状规则 (m×n)·(n×p)）
  - 转置
  - 单位矩阵
- **阶段 2 函数和导数**：
  - 函数就是输入到输出的规则，打一张数值表看函数
  - 斜率和变化率
  - 数值导数（差商，h 越来越小）
  - 常见函数的导数，用数值验证
  - 链式法则（复合函数，数值验证）
  - 偏导数和梯度（多个输入）
  - 梯度下降：一维、二维，找最低点，步长太大会怎样
- **阶段 3 指数对数和概率**：
  - 指数增长和 `math.exp`
  - 对数是指数的反操作，log 把乘法变加法
  - 均值、方差、标准差
  - 概率和频率：用 `random` 加固定种子模拟抛硬币、掷骰子
  - 期望值
  - softmax：把一组分数变成概率，以及数值稳定的减最大值写法
  - 交叉熵（log 概率），这是给机器学习线铺的路

**前置**：可以跨线指向 `py.*`，比如列表、嵌套列表、函数、循环、`py.value-types` 里的 float。根线 `data.shapes` 和"矩阵形状"有关，可以引用。

### 2. 题（`problems/math/<阶段>/`）

- **数量**：约 60–80 题，每个技能按"预测 → 补全 →（改错）→ 独立写"搭阶梯。
- **编号**：题号 `math-<阶段>-NNN-slug`，order 从 10 起、步长 10。
- **比较**：浮点结果用 `compare: float`（容差见格式文档）。
- **随机**：模拟题固定种子，或者把随机数作为参数传进来，保证可判。
- **测试**：每题 `wrong_examples`。数学题的典型错误要能被测试抓住，比如：
  - 点积写成对应相乘但没相加
  - 矩阵乘法行列搞反
  - 差商用了太大的 h
  - 方差除以 n 还是 n−1（题面要写清用哪个）
  - softmax 没减最大值导致溢出：要有大数值的用例
- **场景**：用生活或者后续用途的场景。比如：
  - 购物车总价是点积
  - 成绩加权是点积
  - 推荐系统的相似度是点积和余弦
  - 梯度下降找最便宜的进货量
  - softmax 给三个候选打分

### 3. 课

每个组一个课文件：`math-<阶段>-lNN-…`。
- 每个技能都要有：讲解（read）、可运行示例（example，带步骤名，要能在 playground 跑出注释写的结果）、小测（quiz，针对具名误解）。
- 讲解里可以用 Markdown 表格展示数值表、用 LaTeX 风格的简单公式。先确认现有 Markdown 渲染支持什么：看 `web/src/components/Markdown.tsx`。不支持公式就用文字和代码表达，不要引入新依赖。
