# 31 · 界面改成 VS Code 工作台风格，字体统一打包（Helvetica 风格 + 中文 + 等宽）

## 背景

用户 2026-11-23 的两句话：
- "然后UI可以优化一下把一个固定字体打包进去行吗 用Helvetica吧"
- "然后整个UI风格就往vs code那样靠好了 就相当于模拟一下在vscode里面写代码的环境的感觉差不多"

用户平时就在 VS Code 里写代码，还开着 Claude Code 的聊天面板，code-dojo 要给他同样的手感。这一版取代原来的 31 号任务（`31-typography-ui.md`，已停掉，没有改任何文件），字体部分照原计划做。

**并行**：30 号任务在同时做 Electron 外壳（`desktop/`、`bootstrap/`、打包）。
- 它会新建 `web/src/components/DesktopBridge.tsx`（桌面版才有的小菜单：立即同步、设置、关于），并在 `App.tsx` 里挂载。
- 你会重构 `App.tsx` 的布局，重构时**保留这个挂载**，把它放进状态栏右侧合适的位置。
- 不要修改 `DesktopBridge.tsx` 本身。如果 30 还没写到，就预留一个状态栏插槽，报告里说明。
- 先读 `codex/PLAN.md`。

除了 `DesktopBridge.tsx` 之外，`web/` 全部归你。后端接口如果需要小的补充（比如快速打开需要一个题目搜索的数据源），可以加，并写测试。

## 设计方向：VS Code 工作台

照 VS Code 的布局和交互习惯做，**不复制它的商标和名字**。图标可以用 `@vscode/codicons`（CC BY 4.0，在"关于"和 LICENSE 里注明出处）。

### 布局，从左到右、从上到下

1. **活动栏**：最左边一列图标，约 48px。
   - 上面依次是：资源管理器（学习线树）、搜索（快速找题）、今日计划、手感统计、知识点。
   - 底部：同步状态、设置。
   - 当前项左边有一条强调色竖线，和 VS Code 一样。
2. **主侧栏**：可以拖宽度，可以用 `Ctrl+B` 折叠。内容是"资源管理器"，像文件树一样展示：学习线 → 阶段 → 单元 → 题目。
   - 题目后面用类似 git 装饰的小标记表示状态：通过、AI 协助、试过、未做，颜色和现有的状态体系一致。
   - 有"复习到期"的题加一个小圆点。
   - 节点可以展开和收起，展开状态要记住。
   - 侧栏顶部的标题行用小号大写风格，比如"资源管理器"，右边放几个小按钮：全部收起、定位到当前题。
3. **编辑区**：多标签页，题目像文件一样打开。
   - **标签页**：标签名带图标，比如 `two-sum.py`、`课 · two-sum`、`欢迎`、`今日计划`。单击题目是预览标签（斜体，会被下一次单击替换），双击或者开始编辑就固定下来，和 VS Code 一样。中键或者 × 关闭标签。
   - **面包屑**：标签栏下面一行，比如 `Python 基础 › 0A › 循环 › 数一数有几个偶数`。
   - **做题页**：默认左右分栏。左边是题面预览（Markdown 预览的样子），右边是 Monaco 编辑器。
     - 题面区顶部切"题目 / 课 / 附加题 N"，这些现在是左栏的标签，挪到这里做成二级标签，或者做成编辑区的分组标签，你选更顺手的方案，报告里写理由。
     - 看数据作答题的编辑器位置放作答区。
   - **欢迎页**：现在的学习地图（两个标签加树）做成"欢迎"标签页。没有打开任何题时默认显示它。
   - **其他标签页**：今日计划、手感统计、知识点页、设置都做成编辑区标签页。
4. **底部面板**：`Ctrl+J` 切换显示，可以拖高度。
   - 面板标签："测试结果"（现在的结果面板：用例标签、期望和实际、stdout）、"输出"（stdio 题的输出、playground 输出）、"问题"（报错，带行号；点击跳到编辑器对应行）。
   - 运行或提交后自动展开，并切到"测试结果"。
5. **辅助侧栏（右侧）**：AI 助教，像 VS Code 里的聊天面板。用 `Ctrl+Alt+I` 切换，现有的 Alt+I 也保留。快捷提问、共享编辑框、修改提示这些都保留。
6. **状态栏**：最底下一条 22px，左右两组。
   - 左边：当前学习线和阶段（像 git 分支那样的图标加文字）、问题数（报错个数）、判题方式（本地 / Docker）。
   - 右边：计时、`行 x，列 y`、语言（Python / SQL / 数据）、"裸写"开关、"助教"开关、同步状态（☁ 已同步 20:49 / 待推送 3）、DesktopBridge 的插槽。
   - 状态栏背景用 VS Code 那种整条强调色。
7. **命令面板**：
   - `Ctrl+Shift+P` 打开命令面板：运行、提交、切换裸写、打开今日计划、切换主题、同步、重置代码……
   - `Ctrl+P` 是快速打开：按题名、题号、LeetCode slug 模糊搜索，回车打开。

### 主题

- **深色**：照 VS Code「Dark Modern」的配色关系。比如编辑区约 `#1f1f1f`、侧栏和活动栏约 `#181818`、边框约 `#2b2b2b`、强调色蓝 `#0078d4`。
- **浅色**：照「Light Modern」。
- Monaco 直接用和它配套的主题（`vs-dark` / `vs`，或者微调过的版本），代码颜色和 VS Code 默认的一模一样。
- 现有的 CSS 变量重新映射到这套配色。原来的琥珀色强调色可以保留一处作为"下一步"的标记，或者全部换成蓝色强调，你判断哪种更像 VS Code 又不丢信息，报告里写理由。
- 深色和浅色切换放进命令面板和设置里。

### 字体（原 31 的计划，照做）

- **界面**：拉丁字母用 **TeX Gyre Heros**（Helvetica 的开源克隆，GUST Font License），把 OTF 转成 woff2，附上许可证。中文用 **Noto Sans SC**（@fontsource 的本地分片）。字体栈写 `"TeX Gyre Heros", "Helvetica Neue", Helvetica, Arial, "Noto Sans SC", sans-serif`。界面字号照 VS Code 的密度，正文 13px 左右。
- **代码**：**JetBrains Mono**，Monaco、面板、结果表、数字都用它。
- **全部打包在本地**，不从网络加载。去掉 IBM Plex Sans 和 Source Serif 4。

### 交互细节

- 快捷键和 VS Code 一致：
  - `Ctrl+B` 侧栏、`Ctrl+J` 面板
  - `Ctrl+P` 快速打开、`Ctrl+Shift+P` 命令面板
  - `Ctrl+Enter` 运行、`Ctrl+Shift+Enter` 提交（这两个是现有的）
  - `Ctrl+W` 关闭标签、`Ctrl+Tab` 切换标签
  - `Ctrl+K Ctrl+T` 切主题，可选
- 记住布局状态：侧栏、面板的开关和尺寸，打开的标签。存 localStorage，读写包 try/catch。
- 路由：现有的 `/p/:id`、`/t/:track` 这些地址要继续能用，打开后对应到工作台里的标签。浏览器的前进后退能在标签之间切换。
- 窄屏（不到 900px）：侧栏和辅助侧栏变成可以呼出的抽屉，只保留编辑区和状态栏。不用做到完美，能用就行。
