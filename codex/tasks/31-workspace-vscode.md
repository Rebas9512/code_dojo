# 31 · 做题页改成 VS Code 那样的布局；全站统一配色，字体打包（Helvetica 风格 + 中文 + 等宽）

## 背景

用户 2026-11-23 先后说了三句：
1. "UI可以优化一下把一个固定字体打包进去行吗 用Helvetica吧"
2. "整个UI风格就往vs code那样靠好了 就相当于模拟一下在vscode里面写代码的环境的感觉差不多"
3. 后来收窄了范围："没事之前的那个树状图感觉还可以，只是进题目以后做题的时候布局往vs code靠一靠就行 外部可以颜色什么的统一一下就行了"

所以这次的范围是：
- **做题页**（`/p/:id`，`ProblemWorkspace`）的布局往 VS Code 靠。用户平时就在 VS Code 里写代码，开着聊天面板，做题时要有同样的手感。
- **首页树状地图**和其他外部页面（题目列表、知识点页、今日计划、手感统计、登录页）**保留现在的结构和布局**，只把配色、字体统一到和做题页一套。
- 之前派过的 `31-typography-ui.md`、`31-vscode-workbench.md` 都已停掉，没有改文件，不用管它们。

**并行**：30 号任务在同时做 Electron 外壳（`desktop/`、`bootstrap/`、打包）。
- 它会新建 `web/src/components/DesktopBridge.tsx`（桌面版才有的小菜单：立即同步、设置、关于），并在 `App.tsx` 里挂载。
- 不要改 `DesktopBridge.tsx`。
- 它的挂载位置：外部页面留在顶栏，做题页放进状态栏右侧。可以在 `App.tsx` 和做题页各留一个插槽，改动尽量少。
- 先读 `codex/PLAN.md`。

除了 `DesktopBridge.tsx`，`web/` 都归你。

## 要做的事

### 1. 做题页：VS Code 那样的布局

参考 VS Code 的编辑器加面板加聊天栏的布局。**不复制它的商标**；图标可以用 `@vscode/codicons`（CC BY 4.0，在许可证里注明出处）。

- **左侧：本单元题目列表**（像 VS Code 资源管理器里同一个文件夹下的文件），可以用 `Ctrl+B` 折叠。
  - 列出当前单元的题，题名前面带题型小图标，后面用类似 git 装饰的小标记表示状态：通过、AI 协助、试过、未做，复习到期的加小圆点。
  - 当前题高亮，点击切换题目。
  - 顶部一行小标题，写单元名，旁边一个"返回地图"的小按钮。
  - 宽屏默认展开，窄屏默认收起。
- **中间：编辑区**，分左右两组，像 VS Code 的拆分编辑器。
  - **左组：题面**。用编辑器标签页的样子，标签依次是"题目""课""附加题 N""＋"，把现在左栏的标签换成这种外观。内容区是 Markdown 预览的样子。
  - **右组：代码**。标签名是文件名的样子，比如 `solution.py`、`query.sql`；预测题叫 `answer.txt`，看数据作答题叫 `answer`。标签下面是 Monaco 编辑器，看数据作答题在这里放作答区。
  - **面包屑**：两组的标签栏下面各有一行，比如 `Python 基础 › 0A › 循环 › 数一数有几个偶数`。
  - 两组之间的分隔线可以拖动。
- **底部面板**：`Ctrl+J` 开关，可以拖高度。
  - 标签依次是"测试结果""输出""问题"：
    - 测试结果：现在的结果面板，用例标签、期望和实际。
    - 输出：stdout 和 playground 的输出。
    - 问题：报错和 traceback，点击跳到编辑器对应行。
  - 运行或提交后自动展开，并切到"测试结果"。
- **右侧：AI 助教**，样子像 VS Code 里的聊天面板。用 `Ctrl+Alt+I` 开关，原来的 Alt+I 保留。快捷提问、共享编辑框、修改提示这些功能都不变。
- **状态栏**：做题页最底下一条 22px，背景是整条强调色，和 VS Code 一样。
  - 左边：学习线和阶段，用分支样式的小图标；问题数；判题方式（本地 / Docker）。
  - 右边：
    - 计时
    - `行 x，列 y`
    - 语言（Python / SQL / 数据）
    - "裸写"开关、"助教"开关
    - 同步状态
    - 上一题和下一题
    - DesktopBridge 的插槽
- **原来的题目栏**：计时、裸写、助教、重置、上一题和下一题这些，挪进状态栏或者编辑器标签栏右边的小按钮。不要丢功能。
- **命令面板**：
  - `Ctrl+Shift+P`：运行、提交、切换裸写、切换助教、重置代码、打开课、开关面板、上一题和下一题、回到地图。
  - `Ctrl+P` 快速打开：按题名、题号或者 LeetCode slug 模糊搜索全部题目，回车打开。在所有页面都能用。
- **快捷键**：和 VS Code 一致。`Ctrl+B`、`Ctrl+J`、`Ctrl+P`、`Ctrl+Shift+P`；`Ctrl+Enter` 运行、`Ctrl+Shift+Enter` 提交，这两个是现有的。
- **记住布局**：侧栏、面板和助教的开关，以及它们的尺寸，存 localStorage，读写包 try/catch。
- **窄屏**（不到 900px）：题目列表和助教改成可以呼出的抽屉；编辑区改成上下排列。能用就行。

### 2. 全站配色统一

- **深色**：照 VS Code「Dark Modern」的配色关系。比如编辑区约 `#1f1f1f`、侧栏约 `#181818`、边框约 `#2b2b2b`、强调色蓝 `#0078d4`。
- **浅色**：照「Light Modern」。
- **Monaco**：用配套的 `vs-dark` / `vs` 主题，或者在它们基础上微调。代码颜色和 VS Code 默认一样。
- **重映射**：把现有的 CSS 变量重新映射到这套配色，首页树状地图、题目列表、知识点、今日计划、统计、登录这些页面**结构不变**，跟着新配色走。
- **原来的琥珀色**：例如地图上的"下一步"节点、继续链接。保留成一个次要的强调色，还是全部换成蓝色，你判断，以和谐、不丢信息为准，报告里写理由。
- **状态色**：通过、协助、试过这几种，在两种主题下都要清楚。

### 3. 字体：全部打包，不从网络加载

- **界面**：
  - 拉丁字母用 **TeX Gyre Heros**（Helvetica 的开源克隆，GUST Font License）。把 OTF 转成 woff2，附上许可证。
  - 中文用 **Noto Sans SC**，用 @fontsource 的本地分片。
  - 字体栈：`"TeX Gyre Heros", "Helvetica Neue", Helvetica, Arial, "Noto Sans SC", sans-serif`。
- **代码**：**JetBrains Mono**。Monaco、面板、结果表、数字都用它。
- **标题**：原来的衬线标题（Source Serif 4）改成 Heros 粗体。
- **字号**：
  - 首页和外部页面：标题层级按瑞士风格重新排，大标题略收字距。
  - 做题页：密度照 VS Code，正文约 13px。
- **去掉**：IBM Plex Sans 和 Source Serif 4 这两个依赖。
