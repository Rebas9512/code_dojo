## 要做的事

前 4 个阶段**用 NumPy 手写**，不用 sklearn：用 `forbid_imports: [sklearn]` 约束。阶段 5 先用纯 Python 写标量自动求导，再用 NumPy 和 PyTorch 对照。

- **阶段 1 回归和梯度下降**：
  - 线性模型是点积：回指 `math.*`
  - 均方误差
  - 解析解（正规方程，用 `np.linalg.solve`）
  - 梯度下降：批量、小批量
  - 特征标准化
  - 学习率太大发散：模拟训练检查 loss 轨迹
- **阶段 2 分类**：
  - 逻辑回归：sigmoid 加交叉熵
  - softmax 回归：多分类，回指 `math` 的 softmax
  - kNN
  - 决策边界的直观理解：预测题
- **阶段 3 聚类和决策树**：
  - k-means：初始化固定，判每轮的中心和标签
  - 基尼不纯度、信息增益
  - 一层决策树（决策桩），再到递归建一棵小树
- **阶段 4 模型评估**：
  - 训练集和测试集划分（固定种子）
  - 准确率、精确率、召回率、F1
  - 混淆矩阵
  - ROC 和 AUC：手算，排序法
  - k 折交叉验证
  - 数据泄漏：标准化要在划分之后
- **阶段 5 自动求导和 MLP**：
  - micrograd 风格的标量 `Value` 类（加、乘、tanh、`backward`，拓扑排序）。Karpathy micrograd 是 MIT 许可，只参考思路。
  - 用梯度检查判反向传播对不对
  - NumPy 手写两层 MLP 的前向和反向
  - 最后用 PyTorch 写同一个 MLP，梯度和手写的对拍
- **判法**：数值结果用 `allclose`；训练过程用模拟训练检查（loss 下降、和参考轨迹一致）；反向传播用梯度检查。
- **典型错误**：
  - 忘了加偏置
  - 梯度符号反了
  - 交叉熵里 log(0)
  - softmax 没减最大值
  - 标准化用了测试集的统计量
  - AUC 遇到并列时没处理
  - k-means 出现空簇

## 通用要求

- **数量**：每个技能按"预测（含形状预测）→ 补全 →（改错）→ 独立写"搭阶梯。题量约 70–90。
- **编号**：题号 `ml-<阶段>-NNN-slug`，order 从 10 起、步长 10。
- **课**：每个组一个课文件 `ml-<阶段>-lNN-…`。
  - 讲解、可运行示例、小测三步都要有。
  - 示例要在 playground 里（按 runtime 用 ds 镜像）跑出注释写的结果。
- **`wrong_examples`**：每题都要有，并确认它们被判错。这条线最典型的错误，见上面"要做的事"。
- **随机性**：一律固定种子（`torch.manual_seed`、`np.random.default_rng(0)`），或者把随机数作为参数传进来。
- **性能**：单题在 ds 镜像里控制在几秒内，别让参考解跑太久。
- **参考来源**：只参考思路，题面和代码自己写。
