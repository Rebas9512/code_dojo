# 02m · 首页地图重做：Python / SQL 两个标签页，树状图展示 track 和单元

## 背景

01 号任务把首页做成了一个从上到下的 track 列表（`web/src/pages/MapPage.tsx`）。用户看了之后说：

> "主页的这里ui也设计一下吧做几个不同的tab 分别承接python和sql，然后树状图之类的展示track和节点（单元）大概这种感觉"

这次把首页改成两个标签页，每页一棵树：
- **树枝是 track**。
- **树枝上的节点是单元**。单元是阶段里的"组"；没有分组的阶段，整个阶段算一个单元。

**并行**：02 号任务在同时改平台（题目页、课、判题、附加题），先读 `codex/PLAN.md`。

你名下的文件：
- 首页：`MapPage.tsx` 和你新建的组件、样式文件。首页样式放在单独的 `web/src/pages/map.css`，不往 `styles.css` 里加。
- `/api/tracks` 这个接口，以及它用到的单元统计。单元统计写成新模块 `server/app/units.py`。`server/app/tracks.py` 是 01 建的 track 配置解析，你只在里面给阶段模型加 `units` 字段。
- `track.yaml` 里的 `units`。
- `problems/algo/skills.yaml` 里阶段 2–5 技能的 `group` 字段。
- 题目列表页 `TrackPage.tsx` 里按单元分小标题的部分。

`server/app/tracks.py` 里 track 的模型 02 也要改，它要给 language、runtime 加 `none`。你只加 `units` 字段，用小补丁改。

## 设计

先读 `.impeccable.md`。要求：
- 安静专注，字少。
- 不做同尺寸卡片网格，不加过渡动画（状态切换是硬切）。
- 深色为主并支持浅色，颜色用现有的 CSS 变量。
- 字体沿用现有的：标题衬线，正文无衬线，数字等宽。

### 布局

**标签页**：
- 页面顶部是两个标签："Python" 和 "SQL"，下划线式的硬切换，不要胶囊按钮。
- 去掉"学习地图"大标题，标签本身就是标题。
- 当前标签记在 URL 里：`/?tab=sql`，默认 python。
- 再记一份在 localStorage，读写都要包 try/catch。

**每个标签页是一棵树，从上往下长**。树分两个方向：
- **竖直方向是 track 树**：用缩进和肘形连线表达前置关系，像文件树，但连线是细线。
- **水平方向是每条 track 的单元链**：一排节点用细线串起来，像地铁线上的站。

Python 标签：
```
认识数据        ○─○─○─○─○─○─○
└ Python 基础    ●─●─◐─○─○─○─○─○─○─○─○─○     （0A 第 0–10 组 + 0B）
  ├ 算法与数据结构  ○─○─○ │ ○─○─○─○─○─○ │ ○─○─○─○ │ …   （阶段之间用一个小间隔或竖线分开）
  ├ 数学（用代码学）  ┄┄┄                         （规划中：虚线、空心）
  └ 数据处理        ┄┄┄
    └ 张量与 PyTorch  ┄┄┄   也要先学：数学
      └ 机器学习手写    ┄┄┄
        └ 训练            ┄┄┄
          └ 手搓 LLM        ┄┄┄
```

SQL 标签：
```
认识数据   ○─○─○─○─○─○─○
└ SQL      ○─○─○─○─○─○        （阶段 0–5，各一个节点；以后阶段分了组就自动变多）
   ┄ pandas 互通：数据处理（规划中）    （一行淡色的旁注，链接到数据处理线）
```

**怎么决定树的形状**：
- 一条线放在哪个标签由 `language` 决定：python 的放 Python 页，sql 的放 SQL 页。
- `language: none` 的根线"认识数据"是 02 号任务新建的。它两个页都放，作为树根。02 还没做完时，这条线可能不存在，代码要能处理。
- 树的父节点取 `requires` 的第一项。如果父线不在本页，就挂在本页的根上。其余前置写成一行淡色旁注："也要先学：数学"。

### 节点（单元）

**形状**：
- 实心小方块或小圆，直径 12–14px，全站统一一种。
- 进度用填充表示：
  - 空心：没开始
  - 部分填充：按 solved/total 从下往上填，或者用一圈弧，二选一
  - 实心：全部通过
- 有"AI 协助"通过的题时，节点上加一个小点。
- **"下一步"节点**：整页只有一个，就是 `next` 指向的那个单元。用强调色加一圈外框标出来。
- 规划中的线：节点是虚线空心，颜色调淡。

**标签**：节点下方显示单元的短名，比如"循环""字符串""数组与哈希"，最多 6 个字，超长用省略号，悬停显示全名。

**线头**：每条线的行首显示名字（衬线体）、`solved/total`（等宽体）、"规划中"标签。点名字进入 `/t/<track>`。

### 选中一个节点

点击或键盘回车选中节点，在树的右边显示详情栏；窄屏时显示在树下面。
- 默认选中当前标签页的"下一步"节点。
- 详情栏的内容：
  - 线名 › 阶段名 › 单元名
  - 进度 `12 / 19`
  - 这个单元的技能列表：技能名 + 状态小点，最多显示 10 个，多了折叠
  - 三个链接：
    - "继续：<下一题标题>"
    - "题目"：链到 `/t/<track>#u-<阶段>-<单元>`
    - "知识点"：链到 `/t/<track>/skills#u-<阶段>-<单元>`
  - 规划中的线显示"规划中"，加上这一单元计划讲什么（取阶段名）。
- 键盘：
  - Tab 能聚焦到节点
  - ← → 在同一条线上移动
  - ↑ ↓ 在线之间移动，落到相邻线最近的节点

### 实现建议

- 节点用 HTML 按钮，绝对定位或用 grid 排都行，方便聚焦和无障碍。
- 连线用一层 SVG 画在节点下面。
- 宽度不够时，单元链换行或者水平滚动。手机宽度下不能出现整页横向滚动。
- 不引新依赖。

## 数据和接口

### 1. `track.yaml` 的单元名

每个阶段可以写 `units`，格式写进 `docs/problem-format.md`（v1.3 那一节补一条，或者升到 v1.3.1，你定）：

```yaml
stages:
  - id: "0A"
    name: 语法基础
    units:            # 可选；键是技能的 group
      0: 值和类型
      1: 变量、运算、输出
      ...
```

- **python 0A**：
  - 0 值和类型（06 号任务会加第 0 组，先写上名字）
  - 1 变量、运算、输出
  - 2 条件和布尔
  - 3 循环
  - 4 字符串
  - 5 列表
  - 6 函数
  - 7 字典和集合
  - 8 元组、排序、推导式
  - 9 类
  - 10 简单递归
- **python 0B**：不写 units，整阶段一个单元。
- **algo**：单元名取 `docs/curriculum.md` 6.3 节的小节名。
  - 阶段 1：1 数组与哈希、2 栈、3 链表
  - 阶段 2：1 双指针、2 滑动窗口、3 前缀和、4 二分查找、5 数学与几何、6 位运算
  - 阶段 3：1 树、2 堆、3 回溯、4 图
  - 阶段 4：1 字典树、2 区间、3 贪心、4 一维 DP、5 二维 DP、6 高级图论
  - 阶段 5：不分组
- **algo 技能的 group**：
  - 阶段 2–5 的技能，按 curriculum.md 6.3 里各小节引入的技能，给 `problems/algo/skills.yaml` 里的条目加上 `group`。
  - 阶段 1 的 group 由 04 号任务加，你不要动阶段 1 的条目。
- **sql**：暂不写 units。

### 2. 题目归到哪个单元

- 取这道题 `introduces ∪ requires` 里属于本线、本阶段的技能，它们 group 里最大的那个就是这道题的单元。
- 一个都没有时，归到按 order 排在它前面的那道题的单元；前面也没有题，就归第一个单元。
- 阶段里一个技能都没有 group 时，整阶段一个单元：id 等于阶段 id，名字等于阶段名。
- 单元里还没有题也要显示节点，total 为 0。技能来自 skills.yaml。

### 3. `GET /api/tracks`

在 01 的字段基础上，每个 stage 加 `units: [{id, name, total, solved, assisted, attempted, skills: [{id, name}], next: {id, title} | null}]`。线级的 `next` 照旧。

再加一个顶层的 `next_unit`：`{track, stage, unit}`，表示这个标签页的"下一步"节点。前端也可以自己从 next 推，你选一种，写进报告。

### 4. 题目列表页和知识点页

`TrackPage.tsx` 和 `SkillsPage.tsx` 在每个阶段下面按单元分小标题，带锚点 `id="u-<阶段>-<单元>"`，首页的链接能跳到对应位置。
